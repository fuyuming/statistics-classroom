# 统计课堂06：指数分布与威布尔分布

公众号：明哥的微生物世界。主题是次数与等待、恒定风险、条件概率、无记忆性，以及威布尔形状参数的含义。

## 文件

- `指数分布与威布尔分布_公众号稿.md`：正文和来源链接。
- `指数分布与威布尔分布_手机预览.html`：本地预览；与配图文件夹放在一起打开。
- `代码/exponential_weibull.R`：逐题打印结果、解释和生成四张图。
- `运行结果/逐题计算结果.txt`：可以直接阅读的控制台结果。
- `运行结果/weibull_comparison.csv`：设定参数下的模型计算结果，不是实验观测数据。
- `文章配图/`：代码生成的中文图。

## 运行

下载完整目录并解压。用RStudio打开R脚本，点击Source运行完整文件。

计算部分只需基础R。绘图前可运行：

```r
install.packages(c("ggplot2", "showtext"))
```

脚本自动根据自身路径定位项目文件夹。若选择代码片段运行，先把工作目录切到本课文件夹，或填写脚本开头的 `project_dir`，再从第一行开始运行。

命令行：

```sh
Rscript 代码/exponential_weibull.R
```

中文编码与字体是两个问题：源文件按UTF-8读取；图中缺字则检查中文字体。脚本尝试查找微软雅黑、苹方、Noto Sans CJK；未找到时，按注释填写 `font_file`。未安装绘图包或中文字体时，计算仍完成并保存，绘图会提示下一步。

CSV使用英文列名和UTF-8；时间单位是年。`shape`是形状参数；`scale_years`是尺度而非一般意义上的均值。

## 关键结果

- 齐次泊松过程λ=0.5/小时，4小时零来电 = 等待超过4小时 = 0.135335。
- 已等2小时再等超过1小时 = 0.606531。
- 猫寿命教学模型λ=0.1/年，已活10年再活过8年 = 0.449329。
- 威布尔shape=2、scale=10年，已持续10年再持续超过8年 = 0.106459。

课堂例题采用既定的指数模型假设；不把它当作真实猫寿命结论。来电、仪器比较均为教学模型。没有真实受试者、学生、微生物实验或个体寿命数据。
