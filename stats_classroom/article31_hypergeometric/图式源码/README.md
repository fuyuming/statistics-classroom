# 重建文章图式

安装Python依赖：`python -m pip install matplotlib numpy pandas pymupdf`。
运行本目录`重建图式.py`，生成文章配图中的11张公式图片（式6分为6a条件概率定义与6b二项条件推导）、2张科学图和课堂封面。
公式统一32pt数学字体与9英寸画布宽，长推导分行；组合概率按精确整数计算后转为浮点绘图，坐标见分布坐标.csv。
封面PDF沿用第10次课版式，去除教师姓名、添加实际授课日期和本篇标识。图1每个点代表一张卡片；图2所有计数均显示，不截断支持集。

公开项目直接保留课堂封面PNG。若同目录有课堂封面_无姓名.pdf，脚本会从PDF重新生成；否则保留PNG，仍可重建全部统计公式和科学图。
