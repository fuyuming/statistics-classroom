## 一、先明确比较的是什么

沿用第11课的教学例题，比较F、G、H三种封装，每种各收集80台**已经失效的记录器**。每台只记录一个主要故障，分为接头开路、电极脱落、主板连接故障三类，各台记录器作为独立观察。

本例先问：**三种封装的总体故障构成是否相同？** 检验水平取α＝0.05，关联效应量报告单项双侧95%置信区间。

先假定三种封装的总体故障构成相同，据此计算各格的预期频数。表1把观察数和预期数放在一起，括号内按**本行合计×本列合计÷总数**计算；例如F组开路的预期数为80×70/240≈23.333台。

*表1｜三种封装的主要故障计数；括号内为预期频数，单位：台*

| 封装 | 接头开路 | 电极脱落 | 主板连接故障 | 合计 |
| --- | ---: | ---: | ---: | ---: |
| F | 40（23.333） | 30（30.000） | 10（26.667） | 80 |
| G | 20（23.333） | 35（30.000） | 25（26.667） | 80 |
| H | 10（23.333） | 25（30.000） | 45（26.667） | 80 |
| 合计 | 70 | 90 | 80 | 240 |

这里比较的是**已失效记录器中的故障构成**。例如F组电极脱落占30/80＝37.5%，分母80是该组已失效记录器数。

表1各格的预期频数均大于5，本例采用Pearson卡方检验，判断三组总体故障构成是否相同。在R中，先把括号外的观察数存成矩阵`tab`，行是封装、列是故障类别，再传给`chisq.test()`<sup>[1]</sup>。

```r
tab <- rbind(
  F = c(open = 40, electrode = 30,
        board = 10),
  G = c(open = 20, electrode = 35,
        board = 25),
  H = c(open = 10, electrode = 25,
        board = 45)
)
# 给行、列维度命名，供report识别比较的变量。
names(dimnames(tab)) <- c(
  "packaging", "fault"
)
fit <- stats::chisq.test(
  tab, correct = FALSE
)
fit
```

```text
Pearson's Chi-squared test

X-squared = 44.792, df = 4,
p-value = 4.393e-09
```

输出中的`X-squared`就是Pearson卡方统计量Q：**Q≈44.792，自由度4，P≈4.393×10⁻⁹**，提示三组总体故障构成不全相同。

再按[第35篇](https://mp.weixin.qq.com/s?__biz=MzkxODE4ODY2OA==&mid=2247484411&idx=1&sn=bae476cc01e8402397401c0b2ac30859)的方式报告关联强度。配套使用`effectsize::cramers_v()`，指定`adjust = FALSE`、`alternative = "two.sided"`，得到**Cramér V≈0.3055，双侧95%近似置信区间为［0.2035，0.3858］**<sup>[2]</sup>。

有了检验结果、V和区间，还可以用第35篇介绍的`report::report()`把它们组织成文字报告草稿，减少逐项摘抄结果的工作。它能够接收`chisq.test()`返回的`fit`。这里`adjust = FALSE`沿用未作小样本偏差修正的V，`ci`和`alternative`指定双侧95%区间<sup>[2]</sup>。

```r
report_result <- report::report(
  fit, adjust = FALSE, ci = .95,
  alternative = "two.sided"
)
report_result
```

本次生成报告中的数值部分为：

```text
chi2 = 44.79, p < .001;
Cramers_v = 0.31, 95% CI [0.20, 0.39]
```

报告将统计量和区间作了四舍五入，P值则简写为P＜0.001。这段报告概括整张表；要进一步回答哪两组不同，下面分别比较F–G、F–H、G–H的完整故障构成。

## 二、比较两组的完整构成，怎样选？

### （一）每次取两行，保留全部类别

先看F与G。取出两组后，仍保留三类故障，组成2×3表：F为40、30、10，G为20、35、25。对这张子表作检验，就是比较**F与G的三类故障总体比例是否相同**。

取出子表后，预期频数要重新算。F与G共有160台，开路合计60台，F组有80台，因此F组开路的预期数变为**80×60/160＝30台**。

本例F–G、F–H、G–H三对子表的最小预期频数分别为17.5、25、15，均大于5，采用Pearson卡方检验。**判断近似条件时，应看各对子表，不能直接沿用原来3×3表的预期数。**

### （二）批量计算，再对三项结果调整

F–G、F–H、G–H共同回答“哪两组的完整构成不同”。沿用[统计课堂19](https://mp.weixin.qq.com/s/Ox3tXlD1XchvU6GSmtiuWg)的思路，把三项放在同一比较族中，本篇采用Holm调整，统一与0.05比较。

`rcompanion::pairwiseNominalIndependence()`可以对多行多列表逐对比较。输入完整的`tab`，`compare = "row"`表示逐对取行、保留全部列；下面只启用Pearson检验，`method = "holm"`指定调整方法<sup>[3]</sup>。

```r
full_pairs <-
  rcompanion::pairwiseNominalIndependence(
    tab, compare = "row",
    fisher = FALSE, gtest = FALSE,
    chisq = TRUE, yates = FALSE,
    method = "holm", digits = 15,
    stats = FALSE
  )
full_pairs
```

返回对象中的`Comparison`标明组对，`p.Chisq`与`p.adj.Chisq`分别是原始、调整P值。例如F–G这一行，**`p.Chisq`≈0.001183，`p.adj.Chisq`≈0.002365**。`digits = 15`用于保留计算精度；配套对各对子表另算Cramér V及区间，合列于表2。

*表2｜完整三类故障构成的两两比较；区间为单项双侧95%近似区间*

| 组对 | Cramér V | V的95%区间 | Holm调整P |
| --- | ---: | --- | ---: |
| F–G | 0.2903 | ［0.1185，0.4364］ | 0.002365 |
| F–H | 0.5045 | ［0.3421，0.6540］ | 4.298×10⁻⁹ |
| G–H | 0.2588 | ［0.0826，0.4040］ | 0.004714 |

**三对的完整故障构成都检出差异。** V概括每一对封装与故障类别的关联强度，区间反映估计的不确定性。具体怎样不同，还要结合各类比例看。以G–H为例，G组主板连接故障占25/80＝31.25%，H组占45/80＝56.25%，相差25个百分点。

## 三、只比较指定类别的比例，怎样选？

### （一）把指定类别与其他类别分开

上面每项检验都比较三类故障的完整构成。如果研究预先只关心**哪两组的电极脱落比例不同**，就把电极脱落单列一类，将另外两类相加，得到“电极脱落、其他故障”两列。表3列出合并后的计数及电极脱落比例，分母仍为各组80台已失效记录器。

*表3｜电极脱落与其他故障的计数及构成比例*

| 封装 | 电极脱落 | 其他故障 | 合计 | 电极脱落比例 |
| --- | ---: | ---: | ---: | --- |
| F | 30 | 50 | 80 | 30/80＝37.50% |
| G | 35 | 45 | 80 | 35/80＝43.75% |
| H | 25 | 55 | 80 | 25/80＝31.25% |

**合并类别后，每次取两组，就得到课件讲过的独立2×2表。** 此时比较的是两组电极脱落的总体比例。本例各对子表的预期数足够大，可用`stats::prop.test()`；在相同的连续性校正设定下，它与同一2×2表的Pearson卡方检验对应。

仍以G–H为例，先作一次两率比较：`x`传入两组电极脱落数，`n`传入各组总数，`correct = TRUE`保留课堂上的Yates连续性校正，`conf.level = .95`请求95%区间<sup>[4]</sup>。

```r
gh <- stats::prop.test(
  x = c(35, 25), n = c(80, 80),
  correct = TRUE, conf.level = .95
)
gh$p.value
gh$conf.int
```

```text
[1] 0.1416447
[1] -0.036273  0.286273
attr(,"conf.level")
[1] 0.95
```

`p.value`是这一次比较的原始P，`conf.int`是第一组减第二组的总体比例差区间。G–H的样本比例差为43.75%−31.25%＝**12.50个百分点**，单项95%区间为**［−3.63，28.63］个百分点**。

本次比例差区间采用**带连续性校正的正态近似**。关于Wald、Newcombe、Agresti–Caffo等比例差区间构造的比较，可参看[统计课堂29《独立样本率之差：置信区间怎样算？》](https://mp.weixin.qq.com/s/bDJiRyRskkiC_UbtZ1FEkw)。

### （二）从单次率比较走到两两比较

按同样的设定，还要计算F–G和F–H。用`rstatix::pairwise_prop_test()`可以一次完成这三对：输入“电极脱落、其他故障”两列计数，逐对运行率比较，再统一调整P值。返回的`p`与`p.adj`分别对应原始、调整P值。

```r
electrode_tab <- cbind(
  electrode = tab[, "electrode"],
  other = rowSums(tab) -
    tab[, "electrode"]
)
category_pairs <-
  rstatix::pairwise_prop_test(
    electrode_tab,
    p.adjust.method = "holm",
    correct = TRUE
  )
category_pairs
```

批量结果中，G–H这一行的**`p`≈0.141645，`p.adj`≈0.424934**。前者与刚才单次调用相同，后者已经考虑三项比较。

表4同时报告比例差、区间与调整P值。比例差的方向均为组对中**前一组减后一组**，各单项区间由相应的`prop.test()`调用取得。

*表4｜电极脱落比例的两两比较；比例差及单项95%区间的单位：百分点*

| 组对 | 比例差 | 比例差的95%区间 | Holm调整P |
| --- | ---: | --- | ---: |
| F–G | −6.25 | ［−22.69，10.19］ | 1.000000 |
| F–H | 6.25 | ［−9.69，22.19］ | 1.000000 |
| G–H | 12.50 | ［−3.63，28.63］ | 0.424934 |

**表4中三对的Holm调整P均大于0.05，均未检出电极脱落总体比例的差异。** 以G–H为例，比例差区间跨过0，样本尚不能确定总体差异的方向。

这与表2中三对完整构成都检出差异的结果不同，因为两种检验使用的信息不同。完整构成比较同时使用三列；只比较电极脱落时，开路与主板连接故障被合成了“其他”。**研究问题决定保留或合并哪些类别，也决定结果怎样解释。**

表2和表4的区间都是**单项95%区间**，用于报告各参数估计的不确定性；两张表的P值则分别对各自的三项比较作了Holm调整。

## 四、两两比较的子表稀疏，怎样选？

前面两种比较的子表都适合卡方近似。如果子表中出现较小的预期频数，就需要考虑精确检验。下面沿用第11课的小样本封装试验，仍然比较两组比例。

**例题：三种封装的合格率比较。** 沿用课件的小样本教学变式，另取30台可穿戴心电记录器，接头分别采用A硅胶灌封、B环氧灌封、C热缩套管封装，每种各10台。每台只采用一种封装，各台检测结果相互独立。

每台先弯折100次，再连接心电模拟器记录10 min。期间无持续≥1 s的数据缺口，判为“合格”，否则判为“不合格”。检测结果见表5。

*表5｜三种封装的小样本检测结果，计数单位：台*

| 封装 | 合格 | 不合格 | 合计 | 合格率 |
| --- | ---: | ---: | ---: | --- |
| A | 1 | 9 | 10 | 1/10＝10% |
| B | 2 | 8 | 10 | 2/10＝20% |
| C | 7 | 3 | 10 | 7/10＝70% |

**问题：A–B、A–C、B–C三对的总体合格率是否存在差异？** 采用双侧检验，预先把这三对作为同一比较族，以0.05为家族错误率控制水平，并报告各组对的效应估计及单项95%置信区间。

A–B、A–C、B–C子表的最小预期频数分别为1.5、4.0、4.5，各对子表都有小于5的预期数。本例选择不依赖卡方近似的**Fisher双侧精确检验**计算单项P值，再作Holm调整。单独比较一对时用课堂的`stats::fisher.test()`；一次算完三对时，用`rstatix::pairwise_fisher_test()`，底层仍逐对调用`fisher.test()`<sup>[5]</sup>。

```r
sparse_tab <- rbind(
  A = c(pass = 1, fail = 9),
  B = c(pass = 2, fail = 8),
  C = c(pass = 7, fail = 3)
)
sparse_pairs <-
  rstatix::pairwise_fisher_test(
    sparse_tab,
    p.adjust.method = "holm",
    alternative = "two.sided"
  )
sparse_pairs
```

批量结果仍用`p`、`p.adj`分别保存原始、Holm调整P值。以A–C为例，**`p`≈0.019767，`p.adj`≈0.059300**。报告效应估计和区间时，可逐对调用`fisher.test()`，从`estimate`、`conf.int`读取；这里估计的是**优势比OR**。

“合格概率÷不合格概率”称为合格优势，前一组的合格优势除以后一组的合格优势，就是本篇报告的OR。OR＝1表示两组合格概率相同，OR小于1表示前一组的合格优势较低。

[统计课堂32](https://mp.weixin.qq.com/s?__biz=MzkxODE4ODY2OA==&mid=2247484386&idx=1&sn=5d2501dbd9e8e814b25f9cc36d15a5e2)按两组样本优势之比估计OR。本例A–C直接由样本计数得到0.0476；`fisher.test()`则在固定本对子表的行、列合计条件下估计OR，得到0.0579，表6采用后者。

表6将逐对取得的条件OR估计、单项双侧95%精确区间，与批量计算的三项调整P值列在一起。

*表6｜小样本合格率的Fisher两两比较及OR区间*

| 组对 | OR | OR的95%区间 | Holm调整P |
| --- | ---: | --- | ---: |
| A–B | 0.462 | ［0.007，10.514］ | 1.000000 |
| A–C | 0.058 | ［0.001，0.721］ | 0.059300 |
| B–C | 0.123 | ［0.008，1.134］ | 0.139557 |

表6中三对的Holm调整P均大于0.05，按本例标准，均未检出两组总体合格率的差异。以A–C为例，两组样本合格率分别为10%、70%，OR≈0.058指向A组的合格优势较低。

A–C的单项OR区间未包含1，而Holm调整P大于0.05。这个区间只针对A–C一次比较，Holm调整P则还考虑本次共有三项比较，两者应按各自的范围解释。**Fisher解决单项检验怎样计算，Holm解决多项结果怎样共同判断。**

上面从`fisher.test()`读取的是OR区间。如果研究事先选定的效应指标是**比例差**，并希望直接得到比例差的精确区间，可以选择课件中的无条件精确方法`exact2x2::uncondExact2x2()`。逐对调用时，`parmtype = "difference"`指定比例差，`nullparm = 0`检验总体比例差为0，`conf.int = TRUE`请求相应区间；最后对这一批原始P值调整。

该函数按“第二组减第一组”定义比例差，输入顺序应与报告方向一致；检验统计量等算法设定还需通过`method`等参数按研究方案选择<sup>[6]</sup>。

比较完整构成时，同样可能遇到稀疏的2×C子表。此时可逐对使用`fisher.test()`作条件精确检验；精确计算量过大时，可以考虑其条件Monte Carlo近似来计算P值。双侧Fisher及模拟的计算思路，分别见[统计课堂21](https://mp.weixin.qq.com/s/HKPL2P8PG3v6H652hFwSkA)和[统计课堂20](https://mp.weixin.qq.com/s/U58fgYZ5BXBh1HWiLU2F9g)。

**子表不稀疏时，也可以使用Fisher精确检验。**

## 五、同样控制FWER，什么时候考虑Hochberg？

### （一）Bonferroni、Holm、Hochberg，哪个更严格？

前面的三个组对都采用Holm。**Bonferroni、Holm和Hochberg的控制目标都是家族错误率FWER**，即这一批检验中至少一次把实际无差异判为有差异的概率。本篇把控制水平设为0.05。

控制误报之外，我们也希望发现实际存在的差异。在确有差异时把它检出的概率，称为**检验功效**。**在错误控制目标相同、适用条件成立时，较高的检验功效是方法的优势。** “检出更少”本身不是选择方法的理由。

在各项原始检验适用的前提下，对于同一组原始P值，**Bonferroni调整P ≥ Holm调整P ≥ Hochberg调整P**。因此，统一与0.05比较时，Bonferroni更严格，Holm居中，Hochberg相对宽松。Bonferroni与Holm允许一般的检验间依赖；**Hochberg的FWER控制要求检验相互独立，或符合特定正依赖条件**。对有关联的检验，要根据具体检验模型判断。

例如，另做一项合格率试验：A、B是两种改进封装，C是共同对照，三组使用彼此独立的记录器。事先只计划A–C、B–C两项比较，均检验“改进封装是否提高合格率”；样本量满足率的正态近似条件，采用单侧Z检验。

若C组这批记录器的样本合格率偶然偏低，A−C、B−C两个率差会同时偏大，两个Z也倾向于一起增大，这就是共享对照带来的正相关。**在这两项Z统计量联合近似二元正态且正相关的模型下，可以考虑Hochberg作近似FWER控制。** 依据是这里的两项单侧Z检验及其联合分布；前面的三组双侧两两比较，需要按自己的检验模型另行判断<sup>[7]</sup>。

### （二）Hochberg的P值调整算法——为什么能先看最大的P值？

本篇预先把FWER控制水平设为**α＝0.05**，即把整批至少一次误报的概率控制目标定在5%。这个0.05由研究方案事先选定。

先单独做一个调整练习。假设开展三个相互独立的封装改进试验，每项使用各自的一批记录器，比较改进封装与对照的总体合格率。三项预先规定的双侧检验均符合各自适用条件，得到的原始P值为：**试验甲0.020、试验乙0.023、试验丙0.040**。这里从这三个P值开始计算，将三项作为同一检验族，以FWER＝0.05为目标，问：Hochberg会拒绝哪些零假设？

先把三个P值从小到大排序。第36篇的Holm按这个顺序使用α/3、α/2、α三个门槛；**Hochberg采用相同的排序门槛，检查方向改为从最大的P值向前**：

1. 先看最大P：若**P≤0.05**，就拒绝全部三项零假设。
2. 未通过，再看第二大的P：若**P≤0.05/2＝0.025**，就拒绝排序前两项。
3. 若仍未通过，再看最小P：若**P≤0.05/3≈0.0167**，就只拒绝这一项。三关均未通过，就没有拒绝项。

本例先看试验丙：**0.040≤0.05**，第一关就通过，因此Hochberg拒绝三项零假设。第36篇的Holm则先看最小P：0.020＞0.05/3，在第一关停止，三项均不拒绝。

这两种方法同样控制FWER，判断却可以不同。下面用两项检验的模型，看看Hochberg整套规则怎样合计误报概率。

为便于演算，假定两项检验事先确定、相互独立，并采用零假设下P值在0到1之间连续均匀分布的理想化模型。因此，一项真实零假设产生P≤0.025的概率就是0.025。本例以0.05控制FWER。两项Hochberg的规则是：**1×最大P≤0.05**时，两项都拒绝；否则，再看**2×最小P≤0.05**，也就是最小P≤0.025，通过就只拒绝这一项。

**如果两项实际都没有差异，任何拒绝都是误报。** 计算整批误报概率时，将“至少拒绝一项”分成两个互不重叠的情形：

**第一部分：至少一个P≤0.025。** 两个P都大于0.025的概率为0.975²，所以至少一个不超过0.025的概率为1－0.975²＝**0.049375**。

**第二部分：两个P都大于0.025，同时都不超过0.05。** 每个P落在这段区间内的概率为0.05－0.025＝0.025；两项独立，因此共同落入的概率为0.025²＝**0.000625**。

第一部分已经覆盖所有“至少一个P很小”的情况；剩下会被拒绝的，就是第二部分“两个P一起处于0.025到0.05之间”的情况。两部分互不重叠，相加得到：

**FWER＝0.049375＋0.000625＝0.05。**

因此，允许最大P与0.05比较，并没有让这套两项规则的整批误报概率超过5%。这里的5%来自整套规则的联合事件，不能把每一关各算作5%后再相加。

**如果只有一项实际没有差异，误报只能发生在这一项。** 无论另一项的结果怎样，Hochberg要拒绝这项真实的零假设，它的P都必须不超过0.05，误报概率因而仍不超过5%。

这段演算说明了两项独立检验怎样控制FWER。多项检验的Hochberg程序同样从大P开始，未通过时逐步收紧门槛；其一般保证需要相应的数学证明，并以本节前述的独立或特定正依赖条件为依据。

### （三）怎样换成统一与0.05比较的调整P值？

前面是让原始P值分别与不同门槛比较。报告时，我们也希望像第36篇那样，让各项调整结果统一与0.05比较，就把门槛的分母乘到P值一边：

- 最小P原本与0.05/3比较：**P≤0.05/3，等价于3P≤0.05**。
- 第二大的P原本与0.05/2比较：**P≤0.05/2，等价于2P≤0.05**。
- 最大P原本与0.05比较：**P≤0.05，等价于1P≤0.05**。

所以，**3、2、1这些乘数，来自三个排序门槛的分母。** 回到试验甲、乙、丙，按从小到大的顺序相乘，先得到**0.060、0.046、0.040**。这些乘积还要保留Hochberg“后面某一关通过，也能把前面的项一起拒绝”的规则。

以第二项为例：它自己的换算值是2×0.023＝0.046；最大P对应的换算值则为1×0.040＝0.040。最大P这一关通过时，第二项也会被一起拒绝。两种途径中有一种成立即可，所以取min(0.046，0.040)＝0.040，作为第二项的调整P值。

从最后一项往前算，就能得到每项的调整P值：

- 第三项：0.040×1＝0.040，调整P为0.040。
- 第二项：0.023×2＝0.046，与后面的0.040取较小值，调整P为0.040。
- 第一项：0.020×3＝0.060，与后面已经得到的0.040取较小值，调整P仍为0.040。

**每个位置取本项及其后所有乘积的最小值，就是从后往前取累计最小值。** 因此，本例三个Hochberg调整P都为0.040，统一与0.05比较时均拒绝。第36篇Holm取累计最大值，是为了保留“前面的步骤都通过”；这里取累计最小值，是为了保留Hochberg的成批拒绝规则。

R把这一步封装在`p.adjust()`中。输入原始P值向量，`"hochberg"`指定Hochberg调整；下面保留`"holm"`作为前篇规则的对照。`test1`、`test2`、`test3`依次对应试验甲、乙、丙。

```r
p_demo <- c(
  test1 = 0.020, test2 = 0.023,
  test3 = 0.040
)
data.frame(
  raw = p_demo,
  holm = stats::p.adjust(
    p_demo, method = "holm"
  ),
  hochberg = stats::p.adjust(
    p_demo, method = "hochberg"
  )
)
```

返回表的`raw`、`holm`、`hochberg`分别是原始P、Holm调整P和Hochberg调整P。排序用于计算，函数返回的结果仍与输入的甲、乙、丙对应；实际结果见表7。

*表7｜独立检验练习的调整结果；统一与0.05比较*

| 检验 | 原始P | Holm调整P | Hochberg调整P |
| --- | ---: | ---: | ---: |
| 试验甲 | 0.020 | 0.060 | 0.040 |
| 试验乙 | 0.023 | 0.060 | 0.040 |
| 试验丙 | 0.040 | 0.060 | 0.040 |

表7中，三项Hochberg调整P确实都为0.040。再用R看一组调整P不完全相同的结果。

沿用上述三个独立封装试验，仍作双侧检验并以FWER＝0.05为目标，另给一组原始P：**试验甲0.001、试验乙0.020、试验丙0.040**。与表7相比，甲、乙的原始P改变，丙保持0.040。下面将这组三个P保存在`p_compare`中，再调用同一个函数：

```r
p_compare <- c(
  test1 = 0.001, test2 = 0.020,
  test3 = 0.040
)
data.frame(
  raw = p_compare,
  hochberg = stats::p.adjust(
    p_compare, method = "hochberg"
  )
)
```

R实际返回的`raw`与`hochberg`两列分别是原始P和调整P：

```text
        raw hochberg
test1 0.001    0.003
test2 0.020    0.040
test3 0.040    0.040
```

两组的最大原始P都是0.040，在0.05水平下，Hochberg都拒绝三项零假设；第一组的调整P为0.040、0.040、0.040，第二组则为0.003、0.040、0.040。**最大P这一关通过，决定三项都拒绝；每项调整P的数值，由整组P的累计最小计算确定。**

**0.05是预先约定的判断水平，不是衡量研究价值的“金标准”。** 表7中的0.060与0.040会在0.05水平下给出不同判定，真实研究仍要结合效应量、置信区间与实际意义解释。这一点可接着读[统计课堂11《P＝0.06，该怎样解释？把P值、效应量和置信区间放在一起看》](https://mp.weixin.qq.com/s/ZwcUQoyq5vk4dw5Nhv74Gw)。

**也不必为跨过0.05而反复改换方法、只挑显著结果报告（p-hacking）。** 比较范围、原始检验与调整方法应依据研究问题及适用条件预先确定，分析后完整报告。采用Hochberg的理由，应是它符合研究条件且具有合理的功效优势。

### （四）为什么前面的三组对仍采用Holm？

独立练习给出了Hochberg适用条件中的一种：三项检验来自三批相互独立的试验。前面的F–G、F–H、G–H则反复使用同一组记录器，例如F–G与F–H共用F组数据。**记录器之间独立，并不使这三个组对检验也相互独立。**

本例没有另外建立这些检验满足Hochberg所需正依赖条件的依据，因此选择允许一般依赖的Holm控制FWER。**若研究设计或统计模型能够支持Hochberg的适用条件，就可以在相同FWER目标下考虑它的功效优势。**

### （五）这些方法在论文中还用吗？

**Bonferroni是应用广泛的多重调整方法。** 2020年一项生态学文献调查中，Bonferroni与序贯Bonferroni合计约占记录到的多重比较方法使用次数的一半。这项调查将普通与序贯方法合并统计，反映的是特定学科的文献情况<sup>[8]</sup>。

**Holm与Hochberg也有近期的实际应用。** 例如：

- **Holm–Bonferroni**：2024年《JAMA Health Forum》一项医生利他性与医疗利用研究，对住院、急诊、医疗费用等主要分析作多重调整<sup>[9]</sup>。
- **Hochberg**：2025年《JAMA》的FAIR-HF2试验，用它共同控制三个主要终点的FWER<sup>[10]</sup>。
- **Hochberg**：2026年卷期的《Nature Medicine》RESET-RA试验（2025年12月上线），用它调整四个关键次要终点，比较临床应答率<sup>[11]</sup>。

这些论文展示了方法的实际应用。**具体选择仍要依据比较范围、错误控制目标，以及各项检验之间的依赖条件。** 接下来把这些依据与前面的分类计数例题放在一起看。

## 六、面对一张新表，按什么顺序选择？

把前面的例子合起来，选择顺序就清楚了：**先确定比较目标，再取出子表，根据子表条件和所需效应指标选择检验方法。** 表8整理了本篇几种对应关系。

*表8｜独立分类计数资料的两两比较选择*

| 比较目标与条件 | 单项检验 | 效应与区间 | R入口（单次／批量） |
| --- | --- | --- | --- |
| 完整构成，2×C子表适合卡方近似 | Pearson卡方检验 | Cramér V及区间 | `chisq.test()`／`pairwiseNominalIndependence()` |
| 指定类别比例，2×2子表适合近似 | 两率比较；明确是否连续性校正 | 比例差及区间 | `prop.test()`／`pairwise_prop_test()` |
| 2×2子表稀疏，采用条件精确推断 | Fisher精确检验 | 原生函数给OR及区间 | `fisher.test()`／`pairwise_fisher_test()` |
| 两组独立二项计数，目标为比例差的精确推断 | 无条件精确率差检验 | 比例差及区间 | `uncondExact2x2()`逐对后`p.adjust()` |

选择检验方法时，还应一并确定**哪些比较需要共同调整**。本篇每一种分析都预先比较三对，因此各自的三个原始P值共同作Holm调整；若只计划各组与一个对照组比较，就按实际计划确定比较范围。

完整构成与电极脱落比例，在文中作为两种分析选择分别演示。实际研究若打算同时检验这两类问题，并控制所有结论合起来的误报风险，就应事先把它们纳入同一调整范围。

本篇预先规定的三项比较以FWER为控制目标，按检验间的依赖条件和功效选择调整方法；采用Holm的依据见上一节，Bonferroni与Holm的算法接第36篇阅读。

## 七、本篇讲了哪些知识？

- **完整构成比较与指定类别比例比较，回答不同问题。** 前者保留全部类别，后者把指定类别与其他类别分开；两两比较的结果可以不同。
- **原始检验要看各对子表的条件。** 取出两组后重新计算预期频数，再选择Pearson、两率近似或精确检验。
- **精确检验与多重调整解决不同层次的问题。** Fisher等方法计算单项P值，Holm等方法对同一比较族共同控制误报风险；采用精确检验后，仍需相应的多重调整。
- **Hochberg同样控制FWER，选择它要有适用条件的依据。** 在独立或符合特定正依赖条件时，它可以比Holm有更高功效；更保守、检出更少本身不表示更好。
- **效应估计、置信区间与调整P值一起报告。** 写清V、比例差或OR，以及区间是单项区间还是经过多重调整的区间。
