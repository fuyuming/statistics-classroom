# Cohen h配图重建

在具备numpy、scipy、matplotlib和中文字体的Python环境中运行：

```sh
python 绘制文章配图.py
```

脚本生成5幅公式和3幅图解/科学图，输出到旁边的文章配图目录。全部是给定模型的确定性计算，没有随机模拟。

- 式1：h的定义及课件50%对30%的计算。
- 式2：n=100时，将p=.5/.1代入方差公式，再开平方算标准误。
- 式3：g在p附近的切线近似；求导给出斜率，一阶近似用该斜率换算小偏差。
- 式4：求导与二项方差的一阶抵消。
- 式5：h估计的近似抽样分布、标准误、Z标准化及95%区间，接续统计课堂25的分布—标准误—区间思路。
- 图1：课件50%与30%分别作角变换，再相减得到h；RD在原始率处单独说明，图1坐标.csv保存输入及变换值。
- 图2：同坐标上下两面板，课件原例30%→50%与变式10%→30%；RD为横向差，h为纵向差，图2坐标.csv保存两个端点及差值。比较横纵投影的思路参考pwr官方教程，具体数字按本课例独立计算。
- 图3：固定样本率.50/.30，人数每组20/100/1000的h区间；图3坐标.csv另存无连续性校正Pearson P。
