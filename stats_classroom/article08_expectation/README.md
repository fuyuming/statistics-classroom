## 结果与对应问题

输出在`运行结果/v2/R`、`Python`、`MATLAB`三个子目录。

Python主脚本同时复现正文四张图；`plot_moments.py`是自动调用的绘图模块。Q图使用20,000次多项模型模拟；模拟不能代替渐近分布的证明。运行结果和配图沿用原路径，以保持文章链接可用。

## 输入与练习

- `数据/binomial_cases_v2.csv`：单样本率对照模型，固定n或p比较近似效果。
- `数据/groups.csv`：两组给定样本量n和总体概率p，不是观察到的比例。
- `数据/categories.csv`：四分类教学计数14、18、22、26；给定概率各0.25。

先核对：小样本精确尾概率0.070190826；率差方差0.00845、精确尾概率0.144336406；Q=4。随后可将四类计数改成10、20、25、25，Q应变为7.5。三个标准化比较的写法仅适用于四类等概率，不可随意换概率后照用。

配套主脚本自动计算给定两组参数的公分母和格点，但正文及新增中文图的阈值、标题按课堂的40/50人模型设置。修改组大小后，应同时检查阈值附近格点条件并修改图文；“半格校正”不能无条件应用于任何取值网格。

## 中文显示与文件编码

源码、数据和结果使用UTF-8。文字乱码时按UTF-8重新打开；Excel读取CSV建议使用“数据→从文本/CSV”并选择UTF-8。Python导出的CSV带UTF-8 BOM，便于Excel识别。R/MATLAB输出为UTF-8。
