# 文章配图源码

在本文目录（上层）运行`python 制图源码/绘制文章配图.py`。依赖与配套Python脚本相同；还需可用的中文字体，如思源黑体/Noto Sans CJK SC。程序读取配套项目的默认CSV，生成两张科学图、一张1080像素宽的公式图及区间图坐标CSV。公式数学字号固定32pt，画布不自动裁切。

此脚本用于重建本文默认9/20、13/20情境；学生改参数后应运行配套三语言脚本查看动态图。封面为沿用的无姓名课堂封面，不由本脚本生成。
