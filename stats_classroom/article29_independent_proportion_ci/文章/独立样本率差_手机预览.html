独立样本率之差：置信区间怎样算？

明哥的微生物世界 · 统计课堂 29

摘要：沿着统计课堂25对率差抽样分布的讨论，理解样本率差为什么能估计总体率差，以及怎样从抽样波动构造置信区间。用同一道题比较Wald、Newcombe和Agresti–Caffo三种方法，再用R、Python或MATLAB动手核对。

大家好，我是明哥。

在统计课堂25《样本率为什么能用Z检验？从一个率走到两个独立率之差》中，我们从二项计数走到样本率和率差，推导了两个独立样本率之差的均值、方差与正态近似，并计算过Wald置信区间。

这篇沿着那条线继续往下看：为什么用样本率差估计总体率差？知道它在重复抽样中怎样波动后，又怎样给出一个区间？

先用一道完整例题把抽样分布、点估计和区间估计接起来，再以第25篇的Wald区间为起点，比较Newcombe和Agresti–Caffo两种构造。

一、先把题目读完整：两批人，A减B

假设从A、B两个目标人群中，分别独立随机抽取20人。两组人员互不重叠，各人之间相互独立；在同一评价时点，使用相同检测方法和阳性判定标准，每人记录一次阳性或阴性结果。得到：

组别阳性阴性合计
A组91120
B组13720

我们要回答：A人群总体阳性率减去B人群总体阳性率，点估计是多少，双侧95%置信区间又是多少？ 下面统一按“A减B”计算。

记两个未知总体阳性率为pA和pB，待估参数为δ＝pA−pB。在本题的二项模型下，两组阳性人数分别服从二项分布，且彼此独立；每组内各人共享该组的阳性概率。

本次样本给出A组9/20＝45%，B组13/20＝65%，所以样本率差d＝0.45−0.65＝−0.20，即−20个百分点。

这里的“20个百分点”表示两个百分数直接相减；相对变化则还需选定作为分母的基准率。

图1｜每个圆点表示一人，蓝色表示阳性，浅灰表示阴性。A、B两组各20人。

二、从抽样分布，走到点估计与置信区间

（一）为什么用样本率差估计总体率差？

本题的总体率差δ＝pA−pB是未知而固定的参数。按同样设计重新抽样，A、B两组的阳性人数都会改变，算出的样本率差也会改变。把这个随抽样变化的统计量记为D＝p̂A−p̂B；本次观察到的具体值记为d＝−0.20。

第25篇已经求出：D的期望等于总体率差δ；两组独立时，D的方差等于两个样本率的方差之和。 沿用本题记号，写成：

式（1）｜D是抽样前会变化的样本率差，δ是固定的总体率差；pA、pB是两个总体阳性率，nA、nB是各组样本量。这两条关系在本题的独立二项模型下成立。

期望等于δ，表示按相同规则反复抽样，样本率差的长期平均等于总体率差。因此，D是δ的一个无偏估计量，本次得到的d＝−0.20就是δ的点估计。 一次点估计还可能偏离真值；式（1）中的方差进一步描述这种抽样波动有多大。

（二）怎样从抽样波动得到一个区间？

把D的方差开平方，就得到它的理论标准误SE(D)，也就是率差抽样分布的标准差。第25篇进一步说明，在正态近似适用时，用D减去真实率差δ，再除以理论标准误，所得统计量可近似看作标准正态。

标准正态分布中约95%的概率位于−1.96到1.96之间。把这个概率关系中的δ移到中间，就得到一个以D为中心的区间：

式（2）｜第一行括号内的事件可等价改写为第二行：先衡量D离真实δ有多少个理论标准误，再把δ移到两个端点之间。近似号来自所用的正态近似。

抽样前，D会变化，所以式（2）的两个端点也会变化。反复抽样并计算这些区间，希望约95%的区间覆盖固定的δ。这就是从抽样分布走到置信区间的联系。

但理论标准误含有未知的pA和pB，式（2）的区间规则还不能直接用数据算出端点。Wald方法用本次两组样本率替代各自的总体率，估计标准误，再计算区间。 代入观察到的d后，得到：

式（3）｜p̂A、p̂B是本次样本率；估计标准误衡量样本率差的抽样波动，区间为d加减约1.96个估计标准误。

式（3）沿用第25篇估计一般率差时的未合并标准误，分别保留两组各自的率。代入本题，估计标准误约为0.15411，即15.41个百分点；误差限约为30.21个百分点。

因此，Wald区间为（−50.21，10.21）个百分点。我们按A减B计算：负值表示A总体率较低，正值表示A总体率较高，0表示两总体率相同。

这个区间同时容许一定范围内的负向差异和正向差异。0也在区间内，表示零差异仍是一个候选值，不能据此断定两总体率相等。

式（1）的期望、方差关系是独立二项模型的性质；从它们走到Wald区间，还使用了正态近似和标准误的样本估计。本篇三种区间采用近似构造，设定双侧95%置信水平后，实际覆盖率仍会随样本量和真实阳性率变化。

三、三种构造，各自在处理什么？

（一）Wald：把本次估计的标准误固定下来

Wald先算出d和一个标准误，再在d两侧各延伸1.96个标准误，得到式（3）的区间。阳性或阴性人数很少时，标准误的样本估计可能失真，区间覆盖表现较差[1]。

第25篇用各组n p̂(1−p̂)是否达到10，粗略筛查Wald近似的适用性。本题两组分别为4.95和4.55，未达到这个经验门槛。因此这里把Wald列作比较的起点，再看另外两种区间构造。

R的DescTools包可以直接计算[2]：

xA <- 9
nA <- 20
xB <- 13
nB <- 20
confidence <- 0.95
wald <- DescTools::BinomDiffCI(
  xA, nA, xB, nB,
  conf.level = confidence, method = "wald"
)
wald
#       est     lwr.ci    upr.ci
# [1,] -0.2 -0.5020507 0.1020507

前四个参数依次是A组阳性数、A组总人数、B组阳性数、B组总人数；conf.level给置信水平。返回矩阵中的est是样本率差，lwr.ci、upr.ci是区间下限和上限。端点乘100，就换成“百分点”。

（二）Newcombe：先照顾每组率的不确定性，再组合

统计课堂14介绍过单个率的Wilson得分区间：把候选总体率代入标准误，找出与样本率相容的候选值范围。现在要估计两个独立总体率之差，可以进一步利用两组各自的Wilson区间。

Newcombe把两组Wilson区间提供的两侧距离组合起来，构造率差区间。这里采用其1998年独立样本论文中的方法10，不作连续性校正[1]。

本题两组各自的95% Wilson区间为：A组（25.82%，65.79%），B组（43.29%，81.88%）。从d向左延伸时，取“A样本率到A下限”和“B上限到B样本率”的距离，平方、相加、开平方，得到左侧误差限；向右延伸时，则组合“A上限到A样本率”和“B样本率到B下限”的距离。

例如，左侧两段距离约为0.191802和0.168808，合成的左侧误差限约为0.255508；从−0.20减去它，下限就是−0.455508。这样得到的率差区间为（−45.55，10.06）个百分点。左右两侧分别合成距离，因此误差限可以不同。

沿用前面的R变量，只需明确换方法：

newcombe <- DescTools::BinomDiffCI(
  xA, nA, xB, nB,
  conf.level = confidence, method = "score"
)
newcombe
#       est     lwr.ci    upr.ci
# [1,] -0.2 -0.4555079 0.1006339

method = "score"对应这里的Newcombe构造，返回字段与前面相同。

（三）Agresti–Caffo：先作小幅调整，再套Wald形式

还有一种容易动手的办法：在计算中给每组各加1个阳性和1个阴性，也就是阳性数加1，总人数加2，再按调整后的率与人数计算Wald形式的区间。这是Agresti–Caffo调整[3]。

本题用于计算的两个率变为10/22＝45.45%和14/22＝63.64%，调整后的差值约为−18.18个百分点。按调整后率差作为计算中心，得到（−47.11，10.75）个百分点。

下面用method = "ac"计算：

ac <- DescTools::BinomDiffCI(
  xA, nA, xB, nB,
  conf.level = confidence, method = "ac"
)
ac
#       est     lwr.ci    upr.ci
# [1,] -0.2 -0.4711246 0.1074882

输出中，est列是原始样本率差−0.20；这个区间的计算中心为−0.181818。

图2｜每条横线是一种方法的95%区间，竖虚线表示总体率差为0。三行圆点均标原始样本率差−20个百分点，便于比较；Agresti–Caffo区间的计算中心另用菱形标出。

三种构造都给出了跨过0的区间。以Newcombe为例，结果可报告为：

A组20人中9人阳性（45%），B组20人中13人阳性（65%）。两组率差（A减B）的点估计为−20个百分点，95%置信区间为−45.55至10.06个百分点（Newcombe法，无连续性校正）。

本题中，Newcombe区间最窄。评价一种区间方法时，还要看它在不同样本量和真实阳性率下的覆盖率与区间长度；原始方法论文比较的正是这些重复抽样性质[1,3]。

五、使用前，先看设计与计数

这三种计算用于两组独立的二项资料。每组人数在抽样前确定，每个人记录一次阳性或阴性，同组观察相互独立并具有共同的阳性概率。 两组人数可以相同，也可以不同。

本题中，两组采用相同的检测方法与判定标准，比较的是同一定义下的阳性率。

计数接近0或全部阳性时，三种构造的差别尤其明显。例如两组都为0/20，原始样本率差为0，Wald会算出（0，0）；同一资料用Newcombe得到的区间约为（−16.11，16.11）个百分点。

Wald把两个样本率0代入标准误后，两个方差项都变成0，区间随之缩成一个点。Newcombe先计算每组的Wilson区间，零计数时仍保留一个范围，再组合两侧距离得到率差区间。

六、用一种熟悉的语言跑通，再改参数

配套项目提供R、Python和MATLAB三个入口，可选择一种语言复算表中的三种区间。

就本篇这类专门统计区间的计算而言，R的优势在于现成函数较丰富、参数设置集中，便于作为主要计算语言。 例如BinomDiffCI()通过method选择构造、conf.level设置置信水平、sides指定单侧或双侧区间，可以在同一接口下比较多种方法[2]。

R入口为代码/independent_ci.R，三种区间直接调用DescTools的BinomDiffCI()。

Python入口为代码/independent_ci.py，三种区间直接调用statsmodels的现成函数confint_proportions_2indep()，通过method选择构造。下面是Newcombe的调用[4]：

from statsmodels.stats.proportion import confint_proportions_2indep

xA, nA = 9, 20
xB, nB = 13, 20
confidence = 0.95
lower, upper = confint_proportions_2indep(
    xA, nA, xB, nB,
    method="newcomb", compare="diff",
    alpha=1-confidence
)
print(lower, upper)
# -0.4555079... 0.1006339...

第一组传A，第二组传B；compare="diff"计算第一组率减第二组率，即A减B，alpha=0.05对应95%置信水平，返回的lower, upper就是下限和上限。Wald和Agresti–Caffo分别用method="wald"和method="agresti-caffo"。

MATLAB入口为代码/independent_ci.m。本项目的MATLAB脚本按公式分步计算三种区间，使用基础MATLAB函数，无需统计工具箱。 可以逐节查看标准误、两组Wilson端点及最终区间怎样算出。

三套脚本读取同一份数据/independent_counts.csv，结果显示在控制台和图窗口中。具体运行步骤见项目README。

跑通后做三个小练习，每次改完都重新从读取数据开始运行：

  1. 将共享CSV改为A组45/100、B组65/100，每组人数扩大到100人，两个样本率保持不变。点估计仍是−20个百分点，区间会怎样变化？
  2. 恢复9/20和13/20，只把脚本中的confidence改成0.90。两侧留下的余地怎样改变？留意输出和图标题是否都已更新。
  3. 将两组都改成0/20，比较三种区间，检查Wald为什么退化为（0，0）。然后恢复原始数据，核对主例题。

这些改动分别考察样本量、置信水平和边界计数的影响。每次只改一项，比较起来更清楚。

七、本篇讲了哪些知识？

  • 在独立二项模型下，样本率差D的期望等于总体率差δ，所以D是δ的无偏估计量。 本次观察到的d给出点估计；D的方差则描述重复抽样时的波动，两组独立时为各组样本率方差之和。
  • 率差的方向和单位要固定。 样本率差−0.20表示A组样本阳性率低20个百分点。交换组别后，点估计变号，区间端点变号并交换次序。
  • 置信水平相同，区间构造仍可以不同。 Wald在样本估计处计算标准误；Newcombe组合两组Wilson区间的两侧距离；本篇Agresti–Caffo给每组加1阳性、1阴性后计算，区间中心可以偏离原始率差。
  • Wald区间把抽样波动换成点估计两侧的误差限。 它还借助正态近似，并用样本率估计标准误；本篇三种构造都是近似方法，实际覆盖率随样本量和总体率变化。
