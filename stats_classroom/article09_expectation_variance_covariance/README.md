# 统计课堂09：期望、方差、协方差

第6次医学统计学课程的补充阅读。沿用两独立二项模型与四类等概率教学例，解释率差方差与Pearson Q。没有真实实验、学生个体或个人信息数据。

## 下载后怎么运行

完整解压仓库，进入 `stats_classroom/article09_expectation_variance_covariance`，保留代码、数据、配图的相对位置。

- **R**：打开 `统计课堂09.Rproj` → 打开 `代码/moments.R` → Source完整运行。只需基础R。
- **Python**：在Spyder中用“项目→新建项目→现有目录”选择本篇目录；打开 `代码/moments.py`，F5完整运行。依赖见requirements.txt，在Spyder实际使用的解释器环境中安装。主脚本自动调用 `plot_moments.py` 生成公众号配图。
- **MATLAB**：把Current Folder（当前文件夹）切到本篇目录，打开 `代码/moments.m` 并Run。只用基础MATLAB，不需统计工具箱。“设置路径”用于函数搜索，不等于改变工作目录；本脚本也可根据自身位置找到数据。

命令行备选：`Rscript 代码/moments.R` 或 `python 代码/moments.py`。

结果分别保存到 `运行结果/R`、`运行结果/Python`、`运行结果/MATLAB`。每套都有逐题文字、理论结果CSV、模拟数据；R和MATLAB另有英文标签的Q核对图。Python负责完整的三张中文文章图；三语言主计算内容相同。

## 中文显示

源文件和数据均为UTF-8。源代码乱码时按UTF-8重新打开；这与绘图字体是两件事。Python尝试使用微软雅黑、苹方、思源黑体等字体；无中文字体时先保存计算结果，再提示安装字体。R/MATLAB核对图用英文标签以便跨系统显示，控制台解释是中文。

## 输入与修改

- `数据/groups.csv`：两独立组的标签、样本量n、给定总体阳性概率p。这是模型参数，不是观察到的率。
- `数据/categories.csv`：四类的标签、教学观察频数observed、零假设概率p。观察频数14、18、22、26，总数80；概率事先给定为各0.25。
- 修改组内p、n，可观察率差中心和方差变化。
- 把分类计数改成10、20、25、25，Q变为7.5，仍等于三个比较平方之和。
- 三个比较的具体形式只适用于四类等概率；脚本检查这一条件，不能只修改概率后继续照用这三个方向。

所有CSV均无缺失。输入不是原始实验数据；运行结果中的抽样数据是模型模拟。每种语言随机种子相同，不保证随机序列相同。
