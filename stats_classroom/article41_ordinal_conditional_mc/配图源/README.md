# 当前稿的公式、图与预览源

普通阅读只需打开`手机预览.html`，无须安装构建依赖，预览不依赖联网数学脚本。

- `构建预览.py`：从正文Markdown中的标准LaTeX行内记号生成MathML，需`latex2mathml`；`preview_base.py`为本篇随附的基础Markdown转换器。正文与式图使用相同的数学字体系列，支持下标、上标、均值横线、估计帽和科学计数法。公式图片设置明确的显示宽度、`max-width:100%`和等比高度，居中显示。
- `生成公式.py`：重建7张公式PNG，包括式（1）、表1数值代入的式（1a）及式（2）至（6），需`latex2mathml`、`playwright`及本机Chrome；默认使用Chrome，可用`CHROMIUM_EXECUTABLE`指定其他已安装的Chromium。按内容定宽，源画布最大680 CSS像素；多行公式按等号对齐，长式分行。
- `公式样式.json`：生成器与预览共用的字体、字号和缩放参数。本篇主数学字号以36 CSS像素、双倍像素导出，再按0.5倍源画布宽度显示，实际主字号为18 CSS像素；各图均采用这一比例。短公式保留内容对应宽度，图片自然宽度除以4即预览CSS宽度。上下标按数学层级自然缩小。18像素为本篇排版选择。
- `生成条件分布图.py`：需numpy、pandas、matplotlib（可按配套项目requirements.txt安装），读取配套项目当前R的枚举概率与模拟T结果，使正文765次极端与图一致。支持本地完整材料中的配套项目子目录，以及GitHub中正文与练习文件位于同一目录的布局。若结果尚未生成，先在项目根设置ARTICLE41_SAVE_RESULTS=1运行R主脚本。

先运行公式／科学图生成脚本，再运行构建预览脚本。正文为唯一文章内容源。科学图由实际计算绘制；封面沿用已认可的第11课无姓名版本，不作为科学图编号。这里的构建依赖只供重建配图和预览，三语学生项目按其自己的README运行。
