# 统计课堂27：配对样本率差练习

这些脚本围绕一个问题：每个人的前后变化怎样合成样本率差D的分布？例题和CSV均为教学构造。Zᵢ=后测结果−前测结果，D是所有Zᵢ的平均数；模型给定q₊=.05、q₀=.70、q₋=.25。

## 先打开项目，再逐节运行

完整解压下载包，进入`配套项目`。选择熟悉的一种语言即可；第一次从文件的准备节开始，按顺序读注释、运行代码、查看命名结果对象。循环、函数定义和多行表格构造请作为完整代码块运行。每份主题文件都包含自己的准备步骤。

| 顺序 | 打开哪个文件（后缀按所选语言替换） | 这一份解决什么问题 |
| --- | --- | --- |
| 1 | `代码/distribution_basics.R`、`.py`或`.m` | 两人9种结果怎样得到5项率差概率；20人怎样得到231组三类人数与41项率差概率 |
| 2 | `代码/package_functions.R`、`.py`或`.m` | 先手算三组人数概率，再用现成多项分布函数核对 |
| 3 | `代码/paired_rate.R`、`.py`或`.m` | 从20人逐人记录算率差，再分步计算模型的均值、方差、标准误和不同样本量的分布 |
| 4 | `代码/plot_figures.R`、`.py`或`.m` | 从概率表画精确概率柱与正态单格概率点；第3份文件也会自动调用本文件 |

### R与RStudio

打开`配对率差.Rproj`，再打开第1份R文件。在编辑器选中准备节及后续完整代码块，使用Run依次发送到Console；输入某个结果对象名也可再次查看它。例如先看`two`的9行，再看`two_rate`的5行。熟悉分节后，可用Source运行整份文件。

R的基础计算使用自带函数；绘图需要`ggplot2`。缺包时，在RStudio Console运行`install.packages("ggplot2")`，安装后再运行脚本。

### Python与Spyder

在Spyder打开本项目文件夹，并把工作目录设为`配套项目`或其中的`代码`。打开第1份`.py`文件，从第一个`# %%`单元开始，使用Run current cell依次运行。查看`two_combinations`、`two_rate_distribution`、`observed_case`、`summary`等对象；在Console输入对象名可再次显示，也可在Variable Explorer打开数表。

导入、路径和参数都在准备单元中；后续单元使用前面已准备的变量。整文件运行可用Run file/F5，分节运行时无须先全文件预跑。终端运行Python时，裸对象名不会自动显示；本练习优先用Spyder逐节学习。

需要`numpy`、`pandas`、`scipy`、`matplotlib`和`seaborn`。缺包时使用Spyder当前解释器安装本目录`requirements.txt`中的依赖，确保安装环境与实际运行环境一致。

### MATLAB

将Current Folder设为`配套项目`或其中的`代码`，在编辑器打开第1份`.m`文件，从第一个`%%`节开始使用Run Section依次运行。查看`two_table`、`two_rate`、`observed`、`summary`等对象。Current Folder决定相对路径的起点，脚本准备节会定位项目并加入代码目录。

基础分布、主例与绘图使用基础MATLAB。`package_functions.m`使用`mnpdf`，需要Statistics and Machine Learning Toolbox；没有该工具箱时可先学习第1份文件的公式计算。

## 怎样读本例结果

- 两人5项概率依次为.0625、.35、.515、.07、.0025，总和为1。
- 20人中(1,14,5)这组人数的安排数为232560，其概率约.07701541；产生D=−.20的9组人数概率相加约.17484084。
- 教学记录的前测率.65、后测率.45，D=−.20，表示下降20个百分点。
- 给定模型的个人方差是.26；n=20时D的方差为.013，标准误约.114。模型量与一次观察结果分别解释。

每个脚本都在相应计算旁说明参数、函数返回值和结果含义，并留了先预测、再改参数的练习。

## 需要保存时再打开开关

默认先计算和查看对象、图形。需要写出CSV时，把相应脚本的`SAVE_RESULTS=False`（Python）、`save_results <- FALSE`（R）或`save_results=false`（MATLAB）改为真；需要保存图形时，改绘图文件的`SAVE_FIGURES`或`save_figures`开关。保存步骤位于可选保存节。

CSV写入`运行结果/R`、`运行结果/Python`或`运行结果/MATLAB`；导出的图写入该语言的`图像`子目录。包中已有同名参考数表，方便先对照；重新导出会更新本语言的文件。
