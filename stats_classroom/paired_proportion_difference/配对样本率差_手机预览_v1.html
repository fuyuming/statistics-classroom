配对样本率差怎样分布？从每个人的变化到精确区间

摘要　从每个人前后结果的差值出发，理解联合分布与多项分布，算出配对样本率差的精确分布、均值和方差，再讨论大样本近似、小样本精确区间，以及率差作为效应量的解释。

最近开始接手本科生《概率与生物医学统计》这门课后半部分的教学。一些需要继续展开的知识点，会和研究生课程的补充内容一起，放在“统计课堂”里，相互衔接、相互补充。

前一篇统计课堂25讨论了两个独立样本率之差。这一篇继续配套本科生第9课《率与率差的估计和检验》，来看同一批对象前后各测一次的情形。

同一个人的两次结果联系在一起。抽样时，一个人带着整对结果进入样本。要理解率差怎样波动，可以先把每个人的两次结果相减，再看这些差值的平均数。

一、先算每个人的变化，再算两个率的差

先看一道教学构造例题。从某个目标人群随机抽取20名成年人，相隔两周，用同一方法和同一判定标准各检测一次，记录阳性或阴性。每个人都有完整的两次记录，不同人的配对记录相互独立。下面先算这批资料，再提出反复抽样时的概率模型。

其中，8人两次均阳性，6人两次均阴性，1人由阴性变为阳性，5人由阳性变为阴性。我们关注后测减前测，回答三个问题。

  1. 这批对象的样本率差是多少？
  2. 如果反复抽取这样的一批对象，样本率差有哪些可能取值，各自概率怎样计算？
  3. 根据这20人的资料，总体率差的95%置信区间是多少？

前测阳性人数为8 + 5 = 13，后测阳性人数为8 + 1 = 9。两次样本率分别为0.65和0.45，后测减前测为−0.20，即后测低20个百分点。

把阴性记为0、阳性记为1。对第i个人，前测记为Xᵢ，后测记为Yᵢ，差值Zᵢ = Yᵢ − Xᵢ就有三种可能。

  • 阴性变阳性，Zᵢ = ＋1。
  • 阳性变阴性，Zᵢ = −1。
  • 两次结果相同，Zᵢ = 0。

式（1）｜配对样本率差是个人前后差值的平均数。

式（1）把两种算法接在一起。先求后测率与前测率之差，或者先求每个人的差值再平均，结果相同。本例的20个差值里，1个为＋1，5个为−1，其余14个为0，因此D = (1 − 5)/20 = −0.20。分母是全部20个人，结果未变的人也在样本中。

二、三类变化的人数，为什么要一起看？

下面从已经观察到的20人，转向反复抽样时的随机结果。设一个人出现＋1、0、−1的总体概率分别为q₊、q₀、q₋。它们都是非负数，相加等于1。总体后测率减前测率记为θ。

式（2）｜总体率差由两个方向的变化概率之差决定。

为什么θ等于q₊ − q₋？两次均阳性的人同时计入前测率和后测率，相减时抵消；两次均阴性的人对两边都贡献0。留下的就是阴转阳与阳转阴的概率之差。

抽取n个人后，＋1、0、−1的人数分别记为N₊、T、N₋。联合分布回答的是，这几个随机人数同时取到某一组数值的概率有多大。 例如，20人里同时出现“1人＋1、14人0、5人−1”的概率是多少？

每个人只进入三类中的一类。不同人独立，并采用同一组变化概率时，这三个类别人数共同服从多项分布。本篇只有三类，也可以称为三项分布。二项分布记录两类人数，多项分布把类别扩展到了三类及以上[1]。

式（3）采用多项分布的标准概率公式，三类变化是其中的三类别情形[2]。

式（3）｜三类人数的联合分布，其中r + t + s = n。

这个系数数的是：同样的三类人数，具体可以发生在哪些人身上。 先看一个3人的小例子，把三人记为甲、乙、丙。要求“2人取＋1、1人取0、没有人取−1”，即r = 2、t = 1、s = 0。

先把三个人排成一列，约定前两位取＋1，最后一位取0。排第一位有3人可选，第二位剩2人可选，第三位剩1人，因此共有3 × 2 × 1 = 6种人员排列。 这就是分子3!的含义，“!”表示阶乘。

但这6种排列中，有些对应同一种实际结果。逐一看：

  • “甲乙丙”和“乙甲丙”：都是甲乙取＋1、丙取0。
  • “甲丙乙”和“丙甲乙”：都是甲丙取＋1、乙取0。
  • “乙丙甲”和“丙乙甲”：都是乙丙取＋1、甲取0。

为什么除以2!？ 两个取＋1的人，内部有2! = 2种排列。比如甲乙交换前后顺序，仍然都是甲乙取＋1、丙取0。因此，每种实际结果被数了2次，需要除以2。

为什么还除以1!？ 取0的只有1人，内部只有1! = 1种排列，没有额外重复。除以1，数值不变；写出1!，是为了对应这一类的人数。

为什么还除以0!？ 取−1的有0人，这一类只有“一人也不安排”这一种情况，因此计数时约定0! = 1。除以0!就是除以1，数值同样不变。

系数示例｜将n = 3、r = 2、t = 1、s = 0代入式（3）的多项系数。

这样，6种人员排列去掉重复后，得到3种不同的实际结果安排。三种安排的率差都为2/3。回到一般情形，先排n个人有n!种顺序；同一类别内部交换顺序，分别产生r!、t!、s!种重复。分子数全部人员排列，分母去掉各类别内部换顺序造成的重复，剩下的就是式（3）所需的安排种数。

再算每种安排的概率。q₊、q₀、q₋分别表示一个人出现＋1、0、−1的总体概率。不同人独立，在“甲＋1、乙＋1、丙0”这一安排中，三人的概率相乘为q₊ × q₊ × q₀；另外两种实际结果也有相同的概率。为便于计算，设教学模型的q₊ = 0.05、q₀ = 0.70、q₋ = 0.25。每种安排的概率为0.05 × 0.05 × 0.70 = 0.00175，三种安排互斥，所以“2人取＋1、1人取0”的概率为3 × 0.00175 = 0.00525。这里只算这一组三类人数的概率。

式（3）后面的q₊ʳq₀ᵗq₋ˢ，则把一组指定安排中n个人的概率乘在一起：r个人取＋1，贡献r个q₊相乘，即q₊ʳ；另外两类同理。某类人数为0时，该类不贡献概率因子。整项概率就是“安排种数 × 每种安排的概率”。

这里有两个不同层面的关系。不同人的记录可以独立；三类总人数却受到N₊ + T + N₋ = n的约束。 一类人数增多，留给其余类别的人数就会减少。

三、配对样本率差的精确分布怎样算？

式（3）给出了某一组三类人数同时出现的概率。现在要算D = (N₊ − N₋)/n的概率，就把所有产生相同D的人数组合归在一起。要使D等于k/n，需满足N₊ − N₋ = k；不同人数组合彼此互斥，因此将它们的概率相加，就得到式（4）。式（4）是本文依据配对资料的三项模型和互斥事件概率相加规则推得的表达式[1,2]。

式（4）｜由式（3）的三项概率，累加所有产生同一率差的人数组合；本文按上述模型推导。

式（4）中的k是＋1人数减去−1人数，可取−n到n之间的整数。r是＋1人数，s是−1人数，其余n − r − s人的差值为0。式（4）的每一项仍是式（3）的“安排种数 × 每种安排的概率”，只是将t换成了n − r − s。 最外面的求和，再把所有满足r − s = k的人数组合的概率加起来。

为了把所有取值看清楚，先设一个总体概率已知的教学模型，q₊ = 0.05、q₀ = 0.70、q₋ = 0.25，每次只抽2人。此时D可能为−1、−0.5、0、0.5或1。

先算D = 0。因为n = 2，所以k = 0，式（4）中的条件r − s = k就变成r = s。r与s还必须是非负整数，且r + s不能超过2，因此求和中只有两组计数。

第一组，r = 0、s = 0。 没有人取＋1，也没有人取−1，其余2人都取0。两人独立，这一结果的概率为0.70 × 0.70 = 0.49。这里只有“第一人0、第二人0”一种安排。

第二组，r = 1、s = 1。 一人取＋1，一人取−1，其余0人取0。这组计数对应两种安排。

  • 第一人＋1、第二人−1，概率为0.05 × 0.25 = 0.0125。
  • 第一人−1、第二人＋1，概率为0.25 × 0.05 = 0.0125。

两种安排互斥，概率相加为0.025。式（4）中的阶乘系数，在第一组等于1，在第二组等于2，正是用来计算每组人数有多少种人员安排。

现在把两组计数代入式（4）。

计算示例｜将n = 2、k = 0代入式（4）。

第一项是两人都不变的概率，第二项是一人＋1、一人−1的总概率。求和符号把这两组都能产生D = 0的计数情况加在一起，所以P(D = 0) = 0.49 + 0.025 = 0.515。 D = 0既可以由两人都未变得到，也可以由相反方向的变化互相抵消得到。

其他取值也逐一计算。

  • D = −1，两人均为−1，概率为0.25² = 0.0625。
  • D = −0.5，一人−1、另一人0，概率为2 × 0.25 × 0.70 = 0.35。
  • D = 0，概率为0.515。
  • D = 0.5，一人＋1、另一人0，概率为2 × 0.05 × 0.70 = 0.07。
  • D = 1，两人均为＋1，概率为0.05² = 0.0025。

这五个概率相加等于1。这就是该模型下D的完整精确分布。 给定其他n和变化概率，也沿用式（4），只是需要累加更多人数组合。

配套脚本用逐人累加的方式实现同一个分布。开始时总差值为0；每增加一个独立对象，原来的每种总差值分别增加＋1、0或−1，并乘以相应概率；产生相同总差值的概率再相加。它与式（4）的组合计算给出同一结果。

四、率差的均值和方差从哪里来？

先看一个人的Z。它取＋1、0、−1，因此期望等于q₊ − q₋。平方以后，＋1和−1都变为1，0仍为0，所以Z²的期望等于q₊ + q₋。

再用Var(Z) = E(Z²) − [E(Z)]²，就得到个人变化的方差。统计课堂08讲过期望、方差及协方差的这些性质[3]。

式（5）｜两个方向的变化都进入波动，方向相减决定均值。

D是n个独立个人差值的平均数。期望仍为θ，各人的方差相加后再除以n²，所以D的方差等于个人差值方差除以n。

式（6）｜配对样本率差的均值和方差，这些关系在模型下是精确的。

在第三节的给定模型中，θ = 0.05 − 0.25 = −0.20，个人差值方差为0.05 + 0.25 − 0.20² = 0.26。抽2人时，D的方差为0.13；抽20人时为0.013；抽1000人时为0.00026。

两个方向的变化可以相互抵消，使平均率差较小，但这些变化仍会产生抽样波动。因此，只知道率差，还不能确定标准误。 例如同样20人，如果5人为＋1、9人为−1，其余6人为0，率差仍为−0.20，但变化人数从6人增加到14人，估计的波动也会增大。

从两次样本率直接推导时，也可以写成“后测率方差＋前测率方差−两倍协方差”。同一个人的两次结果之间的联系，就保留在协方差项里。用个人差值推导，会更直接地把这项联系纳入计算。

五、样本多了，什么时候可以用正态近似？

不同对象的Z独立同分布，且个人变化方差大于0时，随着样本量增加，D的标准化抽样分布趋近标准正态。这是把中心极限定理用到三值变量的平均数上[4]。

式（7）｜由精确均值、方差走到大样本近似。

式（7）中N的第二个参数表示方差。 本节先在第三节给定的变化概率下，直接对照精确分布与正态近似。图1上半部分n = 20，下半部分n = 1000。总差值记为k = N₊ − N₋，图的横轴直接显示率差D = k/n。例如，n = 20时k = −4对应D = −0.20；n = 1000时k = −200同样对应D = −0.20。

图1｜q₊ = 0.05、q₀ = 0.70、q₋ = 0.25。柱为精确概率，点为对应连续区间的正态概率，下半部分横轴作了局部放大，两个面板的横轴范围不同。

图1的正态点按每个整数总差值对应的半格边界计算。总差值k的一格是k − 0.5至k + 0.5，换成率差就是D左右各0.5/n。这样可以把连续曲线下的面积，与某个离散取值的概率放在一起比较。

同样1000人，如果q₊ = 0.001、q₋ = 0.002、q₀ = 0.997，两个方向的期望变化人数只有1人和2人。图2展示这个变化稀少的模型。

图2｜n = 1000，q₊ = 0.001、q₀ = 0.997、q₋ = 0.002。每次抽样平均只有3人发生变化，分布仍有明显的离散特征。

单个样本率来自独立、具有相同阳性概率的二分类观察时，正态近似常用的经验检查是：np ≥ 5且n(1−p) ≥ 5；更保守的规则要求两项均≥10。 这里n是单组样本量，p是总体阳性概率，np与n(1−p)分别是期望阳性人数和期望阴性人数，两项条件需要同时满足[5]。

这些对照说明，配对率差能否采用正态近似，要看三类变化共同形成的分布，不能只凭前测率和后测率各自满足上述二项率条件来判断。 对本文的配对率差区间，我们没有找到一个可以普遍据以判断正态近似是否足够准确的简单人数条件。因此，本文主例直接依据有限样本的精确分布构造置信区间，避免仅凭经验门槛决定是否采用近似。 下一节用ExactCIdiff::PairedCI()完成这一计算。

精确方法也可以用于大样本，只要计算可行。 计算时间取决于样本量、观察结果的位置和所用算法。精确区间的理论覆盖率不低于标称水平，但可能偏保守，也不保证区间最窄[1]。本节接着用大样本例题说明近似区间怎样计算，供理解标准误及比较方法之用。

再设一个用于大样本计算的教学例题，1000人采用与主例相同的配对设计，400人两次阳性，300人两次阴性，50人阴转阳，250人阳转阴。前后率仍为0.65与0.45，率差仍为−0.20。用两类变化的样本比例代入式（6），估计标准误约为0.01612。

式（8）｜1000人教学例题的配对Wald近似区间。

式（8）中的概率用样本比例估计，得到常见的插件标准误。近似95%区间约为[−0.2316, −0.1684]，即后测比前测低16.84至23.16个百分点。这里50人和250人分别贡献两个方向的变化，信息结构与图2不同。

n <- 1000
n_plus <- 50
n_minus <- 250
difference <- (n_plus - n_minus) / n
se <- sqrt(((n_plus + n_minus) / n - difference^2) / n)
difference + c(-1, 1) * qnorm(0.975) * se

实际运行输出如下。

PropCIs::scoreci.mp(b = 250, c = 50, n = 1000, conf.level = 0.95)

实际运行输出如下。

 -0.2319192 -0.1685890

这里摘录输出中的区间部分，完整打印保留在配套结果中。函数按(c − b)/n的方向返回区间，因此输入时将＋1人数放在c、−1人数放在b。

六、怎样依据精确分布计算配对率差的区间？

回到20人的主例题。三种人数为1、14、5，已经观察到的率差是−0.20。总体变化概率仍未知，需要根据这些资料估计总体率差θ。

ExactCIdiff::PairedCI()依据的正是第二节的三项联合分布。它把两次结果相同的概率记为pₜ，并将另外两个概率用θ和pₜ表示[1,8]。

式（9）｜PairedCI的参数表示，θ为总体后测率减前测率。

接下来，函数怎样从观察到的“1人＋1、14人0、5人−1”，找到θ的区间？可以沿着下面四步理解[1,8]。

第一步，给定候选θ，还要考虑不同的pₜ。 例如先考察θ = −0.20。按式（9），pₜ可以在0至0.80之间取值。如果pₜ = 0.70，三种概率为q₊ = 0.05、q₀ = 0.70、q₋ = 0.25；如果pₜ = 0.50，三种概率则为0.15、0.50、0.35。两种模型的总体率差都为−0.20，但变化总量不同，三类人数的分布也不同。因此，给定θ还不能唯一确定分布，pₜ也不能直接固定为样本中的14/20。

第二步，先确定哪些样本结果进入单侧尾部。 20人共有231种可能的三类人数组合，观察到的（1，14，5）只是其中一组。计算下限时，需要确定哪些结果更支持较大的θ，才能把相应结果的概率累加成单侧尾部概率。

这里采用Wang的归纳排序：从“20人全部取＋1”的结果开始，再逐步比较邻近候选结果可以达到的置信下限，把下限较大的候选结果排在前面，直到所有可能结果都有次序。对于观察到的（1，14，5），把它本身及排在它前面的结果合在一起，形成计算下限所用的尾部。这个次序由区间构造逐步确定，不是只按D的数值大小排列。

第三步，累加精确概率，并处理未知的pₜ。 给定θ和某个合法的pₜ，就能用式（3）算出每组三类人数的概率，再把第二步确定的尾部中各组概率相加。随后改变pₜ，在合法范围内寻找这个尾部概率的最大值。这样做，是为了让区间在不同真实pₜ下都能控制误差，而不是只在pₜ恰好等于14/20时成立。

为了看清第三步的“网格搜索”，现在换一个靠近区间下限的候选值：固定θ = −0.45，观察资料仍为（1，14，5）。 此时pₜ的合法范围为0至0.55。下限尾部已经按第二步确定，本例共包含141组三类人数。接下来只改变pₜ，比较这个尾部的概率怎样变化。

所谓网格，就是在待搜索的范围里，先选一排具体数值逐个试算。 例如先在0至0.55之间等距选11个点：0、0.055、0.110，依次到0.550。相邻两点间隔0.055。每试一个pₜ，就按式（9）得到一组三种概率，再用式（3）逐组计算并累加尾部中141组结果的概率。

例如试pₜ = 0.440时，q₊ = 0.055、q₀ = 0.440、q₋ = 0.505。观察组合（1，14，5）本身的概率约为0.004282；其余140组结果也各按式（3）计算概率，再与这一项相加，尾部概率约为0.023753。图3的每一个点，都是这样完成一次“给定pₜ→计算三项概率→累加尾部”的结果。

图3｜依据主例Wang下限尾部计算的概率。横轴为pₜ，纵轴为141组尾部结果的概率之和。上半部分在[0，0.55]试11个粗网格点，阴影标出细搜区域；下半部分放大[0.44，0.55]，试21个细网格点。灰线为密集计算的参考曲线。11与21用于展示步骤，正文函数调用采用60与40；两幅图的横轴和纵轴范围不同。

按函数文档，grid.one用于先粗略寻找极值区域，grid.two用于在相应邻域细找；precision控制置信限的数值精度。正文调用的60与40表示采用较密的搜索设置，置信水平仍由conf.level指定[1,8]。

第四步，寻找区间端点。 双侧95%区间将两侧的错误概率各控制在2.5%。到这里才改变候选θ：每换一个θ，就重新在相应合法范围内搜索pₜ并取最大尾部概率。计算下限时，寻找这个最大尾部概率达到0.025的位置，按该方法取最小解；无解时按参数边界处理。计算上限时，交换＋1与−1的人数，用同样的方法求下限，再反号。由下限形成的单侧区间为[L，1]，由上限形成的单侧区间为[−1，U]；取两者的共同部分[L，U]，得到双侧95%区间。

PairedCI使用完整的三类人数信息，区间随率差及变化人数共同改变。 n12和n21同时给出净变化及两个方向的变化总量，t则给出结果相同的人数。只给一个率差，无法还原这些信息。

ExactCIdiff::PairedCI(
  n12 = 1,   # 后测阳性、前测阴性，即＋1
  t = 14,    # 两次相同，即0
  n21 = 5,   # 后测阴性、前测阳性，即−1
  conf.level = 0.95,
  CItype = "Two.sided",
  grid.one = 60,
  grid.two = 40
)

$estimate给出配对率差−0.20，$ExactCI给出95%区间，约为后测比前测低44.92个百分点至高6.30个百分点。区间同时包含负值、0与正值，这批小样本尚不能把总体净变化的方向估计得很确定。20人与1000人的教学例题有相同的点估计，精度却相差很大。

精确区间的“精确”指统计构造依据有限样本分布。 软件仍需要数值搜索，网格设置会影响计算时间与末位结果。区间末位结果可能随网格设置略有变化。

七、这里的效应量是什么，怎样理解大小？

总体配对率差θ本身就是原始尺度上的效应量，D是它的样本估计。 主例观察到的−0.20表示后测阳性率净下降20个百分点。它来自5人阳转阴与1人阴转阳的共同结果，不能直接解释为“20%的人发生了变化”。实际发生变化的是6/20 = 30%。

原始率差没有通用的小、中、大分界。解释实际意义时，需要结合检测指标、人群、前测水平和预先关心的差异幅度。本例为同一批人前后观察，变化的原因还需要研究设计和其他证据支持。

如果研究方案事先关注“后测率是否至少低10个百分点”，主例精确区间同时容许下降较多、变化很小及略有升高；大样本例题的近似区间则全部低于−0.10。这个10个百分点是这里假设的研究关注点，具体研究应有自己的依据。

也可以沿用统计课堂25介绍的Cohen’s h，描述两次边际率在变换尺度上的差异。后测0.45减前测0.65得到h约为−0.4049[9]。两个教学例题的边际率相同，因此h相同。h只使用这两个边际率，配对率差的标准误和区间仍需要三类变化人数。

八、本篇讲了哪些知识？

  1. 配对样本率差是个人差值的平均数。 每个人的后测减前测取＋1、0或−1，分母为全部配对对象。
  2. 三类人数有联合分布。 不同对象独立、采用共同变化概率时，三类人数共同服从多项分布；人数受到总和为n的约束。
  3. D的精确分布可以直接算。 对所有产生同一N₊ − N₋的人数组合，依据多项分布求概率并相加。
  4. 均值由方向之差决定，方差还要看两个方向的变化总量。 E(D) = q₊ − q₋，Var(D) = [q₊ + q₋ − (q₊ − q₋)²]/n。
  5. 本文主例直接依据精确分布构造区间。 单个率常用的np与n(1−p)均≥5、或更保守地均≥10的规则，不能直接作为配对率差区间的适用条件。Wald和score作为近似方法的计算对照；PairedCI依据三项联合分布构造精确区间，计算可行时同样适用于大样本。
  6. 效应量与精度一起报告。 给出前后率、配对率差及其区间，区分净率差与实际变化比例，结合研究问题解释意义。
