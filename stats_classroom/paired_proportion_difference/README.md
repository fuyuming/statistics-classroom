# 统计课堂27：配对样本率差怎样分布？从个人变化到多项分布

本文从两个人的9种变化出发，合并出5项率差概率，再回到20人的多项分布，计算率差的均值、方差和正态近似。

- [下载本篇完整项目](配对样本率差_完整项目.zip)

下载并完整解压ZIP后，进入`paired_proportion_difference/配套项目`。R、Python和MATLAB按相同问题顺序提供基础分布、现成概率函数、主例及绘图四份主题脚本。每份脚本包含完整例题、参数解释、相邻中文注释、可查看的中间量与练习。

图1/图2由配套绘图脚本生成；`图源/`另提供正文公式图的排版脚本。运行`python 图源/unify_formula_sizes.py`可重绘公式；需要Matplotlib及可用中文字体，脚本会查找本机字体。

本目录讨论给定变化概率下的分布；总体率差的区间估计留待后续篇。
