# 统计课堂09｜置信区间的五个例题


使用R或RStudio，仅需R自带包，无需安装其他包。

1. 解压整个文件夹，用RStudio打开“置信区间练习.Rproj”。
2. 打开R文件夹里的一个脚本，点Source完整运行。每个脚本独立，可任意选择顺序。
3. Console显示结果，Plots显示图；同一图形另存到output，计算结果保存为CSV。
4. 脚本使用英文绘图轴标签以便跨平台显示；中文解释在Console和注释中。公众号配图为中文。

01：两个总体均数差；02：一个总体率；03：两个总体率差；04：一个总体方差；05：两个总体方差比；06：重复抽样看95%覆盖率。

01—05为确定性计算，没有随机种子；06的随机种子为20261012，模拟1000轮，图展示前40轮。修改参数后重新运行可覆盖同名结果文件。

`data`保存文章数据的CSV副本；为方便初学者，脚本同时在开头列出全部输入，不依赖读入CSV。具体来源及改编见“数据来源.md”。图和输出已随包提供，运行后会重新生成。

qnorm、qt、qchisq、qf的第一个参数是左侧累计概率；var的分母为n−1。均数差和率差方向固定为第一组减第二组；方差比固定为第一组除第二组。

部分函数名包含test，但本练习通过$conf.int只取置信区间。不要把不同方法给出的区间差异误认为代码错误。
