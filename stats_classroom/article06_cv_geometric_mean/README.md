# 统计课堂 · 变异系数与几何均数：R / Python / MATLAB 三语言示例

本包对应「明哥的微生物世界 · 统计课堂 06」这一篇：**变异系数（CV）** 与 **几何均数／几何标准差（GM／GSD）**。这两节因课堂时间关系没有在课上展开，脚本一并公开。

三套语言**主文件名一致**（`2-9-几何均数`、`2-10-变异系数`），扩展名分别是 `.R`、`.py`、`.m`；同一道例题在三套语言里用同一份数据、同一统计口径实现。

在仓库首页点击 **Code → Download ZIP**，完整解压后进入 `stats_classroom/article06_cv_geometric_mean`，不要只下载单个脚本。

## 数据是什么

| 文件 | 内容 |
|---|---|
| `data/05.txt` | 10 名患者来源分离株的环丙沙星 MIC（mg/L），全部为正、分布右偏 |
| `data/newborn_2025.csv` | 10 名新生儿的身高（cm）与体重（kg） |

说明：均为教学数据，不含个人身份信息。MIC 示例按二倍稀释系列测定，取值呈离散档位（0.03125、0.0625、0.25、0.5、1.00 mg/L），本组数据不含低于最低测试浓度或高于最高测试浓度的记录；实际数据若含超范围值，需先说明处理方法，不能直接当成精确浓度计算。MIC 是特定菌株在规定条件下的测定结果，汇总得到的中心水平不能替代依据适用折点进行的药敏判读。

## 运行方法

**R**：双击本文件夹的 `医学统计学.Rproj`，再打开 `R/` 下脚本 Source（可逐段运行）。首次运行会提示安装缺失的包（需联网）。

**Python**：

```bash
python -m pip install -r requirements.txt
python 2-9-几何均数.py
python 2-10-变异系数.py
```

计算与中文注释集中在共用模块 `Python/medstats_examples.py`，两个入口文件只负责调用对应例题。

**MATLAB**：需要 Statistics and Machine Learning Toolbox；在本文件夹下打开 `MATLAB/` 中的同名 `.m` 运行（中文文件名可用 `run('2-9-几何均数.m')`）。共用实现为 `MATLAB/medstats_examples.m`。

**结果保存**：默认就会写文件——R 存到 `output/R/`（图、表格与 docx 等；只想到控制台看时先运行 `options(medstats.export = FALSE)`），Python 存到 `output/Python/`，MATLAB 存到 `output/MATLAB/`。图中中文依赖本机中文字体，见下方排查说明。

## 核对统计结果

| 脚本 | 关键数字 |
|---|---|
| 2-9 | MIC（n＝10）：均数 0.225、中位数 0.0625、SD 0.3128；对数尺度 SD 1.3091；**GM 0.1015**、**GSD 3.703**；GM/GSD ~ GM×GSD ＝ 0.0274 ~ 0.3759 mg/L（10 个观测中有 8 个落在这个区间内） |
| 2-10 | 身高：均数 48.898、SD 3.9592、**CV 8.10%**；体重：均数 3.468、SD 0.3913、**CV 11.28%**；结论"体重的相对离散程度更大" |

口径：标准差一律为样本标准差（除以 n−1）；四分位数采用位置线性插值（R 默认 type=7；MATLAB 中按同一规则实现 `q7`）；各统计量由原始数据计算后分别取舍小数，用上表的舍入值重算可能出现末位差异——例如体重 CV，用 0.391 ÷ 3.47 手算为 11.27%，完整值算是 11.28%。

## 几个容易误读的地方

- **GM 与 GSD 不能写成"GM ± GSD"**：GSD 是无量纲的倍数因子（本例 3.703，无单位）。要一起报告就分别写"GM 0.1015 mg/L；GSD 3.703"；要给范围用 GM/GSD ~ GM×GSD。该区间在对数正态模型成立、参数已知时大致覆盖约 68.3% 的个体值，本例参数由样本估计、n 只有 10，只能视为近似描述，且**不是 GM 的置信区间**。
- **计算 GM 不要求数据服从对数正态**，只要求全部观测为正。对数正态假设影响的是它作为"分布中心"的解释与上述区间的概率含义；取对数后图形更接近对称也不足以确认模型（n＝10）。
- **CV 的适用条件**：零点要有自然意义，且均数为正、远离 0。摄氏温度（零点人为约定，换成开尔文 CV 会变）与 pH（本身是对数尺度）都不适合直接算 CV。CV 不受正比例单位换算影响（cm→m 不变），但不等于任意两个变量都可比。
- **右偏不等于不能用算术均数**：要描述"平均消耗""平均费用""总量摊到每个个体"时，算术均数仍是目标指标；它可能不是最有解释力的"典型水平"，但并没有算错。

## 课后练习

1. 用 R 与 Python 各算一遍 MIC 的 GM 与 GSD，核对是否一致；解释 GSD 为什么没有单位。
2. 把某一个 MIC 值改大 8 倍，观察算术均数、中位数、GM 的变化幅度有什么不同。
3. 修改 `data/newborn_2025.csv` 中的一个体重值，观察均数、SD 与 CV 的变化。
4. 用这 10 个观测说明：为什么"取对数后看起来更对称"不能作为对数正态分布的确认依据。

## 中文乱码与字体排查

脚本注释乱码：先按正确编码重新打开，确认后另存 UTF-8，不要直接覆盖乱码文本。

数据乱码：`data/05.txt` 与 `newborn_2025.csv` 均为 UTF-8；如遇其他来源的文件，先核对其真实编码，不要忽略解码错误。

图上中文显示为方框：检查绘图字体，选择本机实际存在的中文字体（R 用 showtext；Python 用 `matplotlib.font_manager` 查询；MATLAB 用 `listfonts`）。改字体不能修复已经读错的文字。
