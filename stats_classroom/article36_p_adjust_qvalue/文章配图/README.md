# 第36篇图源

正文使用第11课无姓名封面及两张公式图，共3张图片。

- `公式01_FWER.png`：FWER独立定义。
- `公式02_FDR.png`：FDR独立定义。
- `公式03_BH规则.png`：旧稿BH通式图，已从当前正文移除，仅作历史图源保留。
- `生成公式.py`可按脚本位置重建，支持`--out`指定目录；白底、同一字体尺寸和颜色。
- 原π₀公式和直方图不用于正文，只作为项目可选扩展的源资产保留。可选说明和运行方法见项目README。

## 可选重建依赖

正文练习无需运行绘图入口。需要重建公式图时，Python环境需安装`matplotlib`；历史P值分布图的R入口需安装`ggplot2`，运行时传入共享P值CSV和输出PNG路径。主练习的依赖仍以项目requirements及README为准。
