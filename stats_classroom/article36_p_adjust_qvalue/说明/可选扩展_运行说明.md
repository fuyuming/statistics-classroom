# 可选扩展：Storey q 值与 π̂₀

本文件只说明项目保留的 02 扩展。它不属于《统计课堂36》正文，完全可以跳过；主练习 `01_p_adjust` 不依赖本扩展，也不需要安装 `qvalue`。

## 入口与依赖

| 语言 | 入口 | 运行位置 |
| --- | --- | --- |
| R | [`scripts/02_storey_q.R`](../scripts/02_storey_q.R) | RStudio 打开项目后按 `##` 分节运行，或整文件 Source |
| Python | [`scripts/02_storey_q.py`](../scripts/02_storey_q.py) | Spyder 将项目根目录设为工作目录，按 `# %%` 单元运行，或 F5 整文件运行 |
| MATLAB | [`scripts/m02_storey_q.m`](../scripts/m02_storey_q.m) | Current Folder 保持项目根目录，先 `addpath('scripts')`，再按 `%%` 运行 |

三种语言仍读取同一份 [`data/screening_pvalues.csv`](../data/screening_pvalues.csv)，无需先运行 R 生成数据。MATLAB 脚本会自行加入 `helpers` 目录；Python 使用 `requirements.txt` 中的依赖。

R02 才需要 Bioconductor 的 `qvalue` 包，安装一次即可：

```r
if (!requireNamespace("BiocManager", quietly = TRUE)) {
  install.packages("BiocManager")
}
BiocManager::install("qvalue")
```

MATLAB 与 Python 02 使用随附的 [`storey_q_fixed.m`](../helpers/storey_q_fixed.m) 和 [`storey_q_fixed.py`](../helpers/storey_q_fixed.py)，不需要 R 后端。命令行入口（均在项目根目录）：

```text
Rscript scripts/02_storey_q.R
python scripts/02_storey_q.py
```

## 固定设置与读法

02 预先固定 λ＝0.5，以 `P≥λ` 的个数估计 π̂₀。本项目的 R 实现使用 `qvalue(..., pfdr=FALSE)` 对应的常规估计模式；在此固定设置下，q 值按 π̂₀ 缩放 BH 调整值，并按实现规则处理边界。

本次固定输入中，`P≥0.5` 有 446 项，因此 π̂₀＝446/(1000×0.5)＝**0.892**；Storey q 筛出 **68** 项。λ 为 0.3/0.5/0.7 的敏感性结果由 02 脚本给出。以上数值是随附输入的既有结果说明，不表示本次重新运行。

公式、配图与输入解释见[Storey π₀ 估计补充](Storey_pi0估计补充.md)。

## 扩展结果与可选保存

默认运行仍只在会话中查看对象，不改写 `results`。需要保存时，先设置：

```text
R:       Sys.setenv(ARTICLE36_SAVE_RESULTS="1")
Python:  import os; os.environ["ARTICLE36_SAVE_RESULTS"] = "1"
MATLAB:  setenv('ARTICLE36_SAVE_RESULTS','1')
```

02 扩展结果 CSV 使用 `R_02_storey_q.csv`、`Python_02_storey_q.csv`、`MATLAB_02_storey_q.csv`，以及对应的 `*_02_summary.csv`、`*_02_lambda_sensitivity.csv`。这些文件与 01 主练习的 `*_01_*.csv` 分开；不设置保存开关则不会写文件。
