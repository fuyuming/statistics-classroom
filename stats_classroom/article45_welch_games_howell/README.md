# 统计课堂45｜Welch与Games–Howell

- `公众号稿.md`：当前唯一MD源稿，完整题干、全部数据、Welch与GH构造和三对结果；第七节为2025—2026年牙釉质与嗅觉研究的实际应用。
- `公众号草稿预览.html`：由官方草稿读回生成，使用已核对的本地图像，保留微信实际正文样式。
- `手机预览.html`：从当前MD派生的手机阅读预览；保持同目录结构打开，图片使用相对路径。
- `文章配图/`：课堂封面、10张高清公式PNG、2张数据图。
- `配图源/generate_figures.R`：用R从共享CSV重建正文两幅数据图及区间坐标。入口为`Rscript 配图源/generate_figures.R`，实际绘图实现位于`练习项目/R/plot_article.R`，随项目ZIP交付。
- `配图源/generate_formulas.py`与`formulas.json`：只负责10张LaTeX公式PNG的排版，入口为`python 配图源/generate_formulas.py`。
- `练习项目/README.md`：R、Spyder/Python、MATLAB新手入口、共享CSV、真实结果和运行限制。
- `统计课堂45_练习项目.zip`：与当前练习项目逐字节一致的便携包。
- `审读与核验.md`：三位独立AI视角审读的处理及主代理成品核验。

配套项目目录：https://github.com/fuyuming/statistics-classroom/tree/main/stats_classroom/article45_welch_games_howell

源稿、预览、配图和练习项目为当前同一套材料；外部同步和审读核验状态见《审读与核验.md》。
