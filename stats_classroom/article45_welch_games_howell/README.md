# 统计课堂45：Welch 与 Games–Howell 配套练习

本目录提供与《方差不齐，三个组的均数怎样比较？》配套的可运行练习项目。完整项目 ZIP 可直接下载：[统计课堂45_练习项目.zip](https://github.com/fuyuming/statistics-classroom/raw/main/stats_classroom/article45_welch_games_howell/%E7%BB%9F%E8%AE%A1%E8%AF%BE%E5%A0%8245_%E7%BB%83%E4%B9%A0%E9%A1%B9%E7%9B%AE.zip)。

解压后进入 `练习项目/`：数据在 `data/hetero_normal.csv`；R 入口为 `R/welch_gh.R`，Python 入口为 `Python/welch_gh.py`，MATLAB 入口为 `MATLAB/welch_gh.m`。各语言的实跑结果和图形分别位于 `运行结果/` 与 `图形/`，可对照 `VALIDATION.md` 核验。

MATLAB 脚本按 MATLAB R2025a 环境编写；不同版本可能需要调整局部语法或绘图选项。
