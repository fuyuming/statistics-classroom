摘要　三组资料的波动相差很大，研究目标仍是平均下降多少，这时怎样比较均数？从一道三种降压方案的完整教学题出发，用各组均数的精度构造Welch整体检验，再逐对计算Games–Howell的标准误、近似自由度、调整P值和同时置信区间，看看同一份数据怎样得到带方向、单位与不确定性的结论。最后对照两项近期研究，看看这套方法怎样用于牙釉质硬度和嗅觉评分的比较。
大家好，我是明哥。
本科《概率与医学统计学》讲到多组均数比较时，会用到Welch和Games–Howell。课堂会讲选择理由和结果判读，课时有限，背后的统计量怎样构造，就放到公众号接着讲。
第43篇整理了经典方差分析的正态性、方差齐性与残差诊断。接下来要解决的是：共同方差不合理，而我们仍想比较总体均数，分析该怎样继续？
Welch把两独立样本的不等方差均数比较推广到多个组；Games–Howell则进一步比较各组之间的两两差异。本篇沿同一道题，从各组均数的抽样波动算起，把统计量、参照分布和最后的研究解释连起来[1]。
一、先把完整题目摆出来
假设一个团队比较三种降压方案G1、G2、G3。36名不同受试者随机分入三个组，每组12人，随访8周。每人记录基线和8周收缩压，并计算基线收缩压减去8周收缩压，得到一个下降值，单位为mmHg；数值越大，表示下降越多。
本题分析的是36名相互独立受试者各自的下降值。一个人的两次测量已经合成为一个差值；不同方案之间是独立组比较。表1按方案分别列出每组12名受试者的全部教学数据，数据按正态模型模拟生成。

设各组下降值的总体分布近似正态，允许各组总体方差不同。本题的总体均数μ1、μ2、μ3分别表示三种方案下的平均下降值，这三个总体均数未知，需要用样本资料推断。检验水准取α＝0.05，要回答：
1. 三种方案的总体平均下降值是否相等？整体H0为μ1＝μ2＝μ3，H1为至少有两个总体均数不同。
2. 如果比较全部三个组对，哪些方案之间的平均下降值有差异？逐对H0为对应的总体均数差等于0，均作双侧比较，并为全部三对作多重比较调整，报告95%同时置信区间。
先明确方法适用的范围。Welch放宽的是共同方差要求，仍需要按研究设计判断独立性，并关注组内分布和极端值。每组只有12人时，严重偏态、重尾或强影响点仍可能使均数及其方差估计不稳定。Welch在这一模型下使用近似参照分布[2]。
如果改用Kruskal–Wallis，分析就转向秩及分布差异；在共同形状的位置模型下，才可进一步作位置差异的解释。研究目标仍为均数时，方差不齐本身并不构成改用秩方法的理由。
二、各组均数的精度为什么不同？
先从表1计算每组样本量、均数和样本标准差。下标i表示组，j表示组内受试者；yij是某人的下降值，ȳi和si2分别为该组样本均数与样本方差，ni为该组人数。本题i＝1、2、3，各组ni＝12。
在同组受试者独立、具有同一总体方差σi2的模型下，样本均数的方差为σi2/ni。用si2代替未知的σi2，就得到式（1）的均数方差估计vi，以及相应的精度权重wi。
式（1）｜vi估计样本均数的抽样方差，单位为mmHg2；其平方根是均数标准误，单位为mmHg；wi为方差倒数，单位为mmHg−2。
样本标准差描述组内个体的差异，均数标准误描述样本均数的抽样波动。 人数相同时，组内波动越大，均数估计通常越不精确；在总体方差相同的条件下，人数越多，均数估计通常越精确。wi把这两方面合在一起。

三、从精度权重构造Welch统计量
（一）先找共同均数的加权估计
如果H0成立，三个总体均数相同，就可以用三个样本均数共同估计这个未知的共同均数。精度高的估计贡献较多，精度低的估计贡献较少。式（2）给出权重总和W与加权均数ȳw。
式（2）｜求和覆盖全部k个组，本题k＝3；ȳw仍以mmHg计。
代入表2，W＝22.9931，ȳw＝9.8524 mmHg。G1占总权重约93.94%，所以ȳw靠近G1均数9.6308 mmHg。
Welch用这个加权均数作为共同中心，接着衡量三个组均数偏离它的程度。
（二）衡量三个均数偏离共同中心多少
有了共同中心，就可以计算每个组均数与ȳw的偏离。式（3）将偏离平方，按精度加权，再除以k−1，得到A。
式（3）｜偏离平方的单位与权重相消，A无量纲；k−1对应k个均数围绕一个共同中心的偏离。
同样大的均数偏离，如果发生在估计很精确的组，就更难用抽样波动解释，因此贡献更大。本题A＝12.377002。
可以先看一个理想情形来理解它：假如各组总体方差已知，在独立正态模型下按真实精度加权，那么H0下的加权离差平方和服从自由度k−1的χ2分布。若把式（3）的权重也换成这些真实精度，得到的量就是上述χ2变量除以k−1。实际资料中，权重来自样本方差，连加权中心也随它们波动。直接沿用“已知方差”的参照会忽略这部分不确定性，Welch因此作有限样本校正。
（三）把方差估计的不确定性纳入校正
式（4）先写出一般k组的关系：定义校正量C，再给出Welch统计量FW及其分母近似自由度ν。这个构造使用各组样本量和权重比例，R的oneway.test()也按这一形式实现[3]。
式（4）｜C、FW、ν均无量纲；ni−1是各组样本方差的自由度。
C中每项都包含ni−1，因为每组方差估计的稳定程度与它的自由度有关；同时包含wi/W，因为不同精度的组对共同中心的影响不同。这些因素汇总成C，用来校正A，并确定参照分布的分母自由度。
本题C＝0.171352。式（5）用k＝3把校正和参照分布接起来。
式（5）｜显示值经过舍入；实际计算保留全部精度。F分布的分子自由度为k−1＝2，分母为近似自由度ν。
式（5）已经用A和C算出了本题的F统计量11.868577。随后得到的ν＝15.562533，用于确定这个统计量的参照分布。
F分布的自由度参数可以取正实数。这里直接使用分子自由度2、分母自由度15.562533的F分布，求临界值或尾部概率。样本算出的F统计量与由参照分布求出的临界F值，在分析中分别承担这两步的作用[3]。
观察到的FW越大，说明组均数相对其抽样波动的偏离越大。用上述F分布计算11.868577及更大值的右尾概率，得到P＝0.0007405。这里虽然只取F的右尾，整体备择仍包含任意方向的均数差异，因为偏离在式（3）中已经平方。
四、用R核对整体检验，它回答到哪一步？
配套CSV有两列：group是方案，value是每人的下降值。打开本篇R项目后，从项目根目录读取它；value ~ group表示按方案比较下降值，var.equal = FALSE明确采用不假定共同方差的Welch方法[2]。
h <- read.csv("data/hetero_normal.csv")
h$group <- factor(h$group, levels = c("G1", "G2", "G3"))
fit_welch <- oneway.test(
  value ~ group, data = h, var.equal = FALSE
)
fit_welch
返回对象中的statistic是FW，parameter保存两个自由度，p.value保存P值。控制台实际输出如下：
One-way analysis of means (not assuming equal variances)

data:  value and group
F = 11.869, num df = 2.000, denom df = 15.563, p-value = 0.0007405
如果用临界值判断，右尾检验α＝0.05对应左侧累计概率0.95。R的qf()输入这个概率和两个自由度，返回临界F值；pf()输入观察到的F和自由度，返回相应概率。代码中的df_welch[1]、df_welch[2]分别读取分子、分母自由度，保留其小数值。
df_welch <- unname(fit_welch$parameter)
F_cutoff <- qf(0.95, df1 = df_welch[1], df2 = df_welch[2])
F_observed <- unname(fit_welch$statistic)
P_right <- pf(F_observed, df_welch[1], df_welch[2], lower.tail = FALSE)
c(F_observed = F_observed, F_cutoff = F_cutoff, P = P_right)
实际算得临界F值为3.654113。观察F＝11.868577大于这个临界值，等价于右尾P＝0.0007405小于0.05。
P＜0.05，在本题模型条件下拒绝三组总体均数相等，支持三种方案的总体平均下降值不全相同。Welch到这里完成的是整体判断；要回答具体哪两种方案之间有差异，还需要逐对比较。
五、Games–Howell：每个组对都有自己的不确定性
全部三对比较是G2−G1、G3−G1、G3−G2。下文用i、j表示前、后两个组，统一取后组减前组：dij＝ȳj−ȳi，正值表示后组平均下降更多。
（一）沿用Welch t的标准误和自由度
每个组对先按两独立样本Welch t的方法处理：用这两个组各自的方差估计均数差的标准误，再计算Welch–Satterthwaite近似自由度。
因为两个样本均数相互独立，差值的方差等于两个均数方差之和。式（6）给出SEij和νij，正是两独立样本Welch t使用的标准误和自由度。
式（6）｜SEij以mmHg计；νij无量纲，只用当前两个组的样本量和方差计算。
自由度为什么也要逐对算？均数差的标准误使用了两个样本方差，两者估计得是否稳定、各占多少，都影响这个标准误的不确定性。如果其中一组的均数方差远大于另一组，差值的不确定性便主要来自这组，近似自由度也会靠近这组方差的自由度。
例如G3−G1，v3＝3.504805远大于v1＝0.046299。按式（6），SE13＝1.884437 mmHg，ν13＝11.290574，接近G3的12−1＝11。其余组对也分别按自己的均数方差和样本量重算SE与ν。
（二）从Welch t转到学生化极差q
如果只比较预先指定的一对，检验H0：μj−μi＝0时，差值除以式（6）的标准误得到tij，参照该自由度的t分布作双侧检验。
现在要同时看三对，Games–Howell沿用每对的标准误和自由度，把|tij|乘√2转到q尺度，再用全体组数k的学生化极差参照进行多重比较，控制三次比较中至少一次错误拒绝真实零假设的概率[4]。
式（7）把同一个均数差分别写在t尺度和q尺度上。两种统计量使用的分母相差√2。
式（7）｜tij保留差值方向，qij使用其绝对值；两者均无量纲。
这里为什么有√2？在等人数、共同方差的Tukey情形，q的分母是单个均数的标准误s/√n，而两个独立均数之差的标准误是√2倍的s/√n。因此，从“均数差标准误”的尺度换到q尺度，要乘√2。Games–Howell保留这个尺度关系，同时将分母换成当前两组各自方差构成的估计。
GH的方差尺度由当前两个组的均数方差相加得到。 三个组对分别计算这个尺度，再结合各自的近似自由度使用q分布。
（三）q分布为什么包含全体组数？
这里的q分布，就是Tukey方法采用的学生化极差分布。统计课堂22《Tukey检验为什么用q分布？多重比较校正在哪里？》已经从均数极差讲过它的来由；这里保留接到GH所需的关系。
为定义这个理论参照分布，取k个相互独立的标准正态变量Z1、…、Zk，再取一个与它们独立、服从自由度ν的χ2分布的变量U。Z的最大值减最小值是极差；把U除以ν再开平方，得到分母的波动尺度。极差除以这个尺度，就得到式（7a）的Qk,ν[5]。
式（7a）｜Z1、…、Zk相互独立；U与它们独立。k是参与取极差的正态量个数，ν描述分母波动尺度的估计精度。大写Q表示参照随机变量，小写qij表示本题组对的观察值；两者均无量纲。
k个数里，最大的两两绝对差就是最大值减最小值。在总体均数相等、观测独立、正态、共同方差且各组样本量相同的Tukey模型中，各组均数共享同一个标准误。把全部组对放在这个共同尺度上比较，最大的标准化组对差异就对应Q的极差参照。
组数k越多，抽样时出现相距较远的一对的机会越多，q参照因此随k改变。ν越大，分母波动尺度的估计通常越稳定。以Q的95%分位点作门槛，在这个参照分布下，超过门槛的概率为5%。
回到本题，三个组对分别使用自己的Welch标准误和近似自由度，GH用Qk,νᵢⱼ逐对作近似校准。三对都保留全体组数k＝3，各自使用νij，所以分位点也逐对计算。√2完成t与q的尺度转换，全体组数k通过极差参照进入多重比较调整。
（四）同一套q参照同时给出调整P与区间
将本题每对观察到的q放入相应的Qk,νᵢⱼ参照，便可按式（8）计算调整P值和近似95%同时置信区间。R的ptukey()在lower.tail = FALSE时给出右尾概率，qtukey()求分位点[6]。
式（8）｜q0.95是参照分布的95%分位点；本题所有组对都用k＝3，各自使用νij。区间端点以mmHg计。
同一个规则可以从两边读：观察q大于95%分位点，对应调整P＜0.05，也对应区间不包含0。式（8）已经把多重比较调整纳入P值和区间，因此不再对这些P值追加一次Bonferroni校正。
“95%同时”针对的是三条区间一起覆盖各自总体均数差的事件，整套覆盖率约为95%；对应检验的目标是把三次比较中至少一次错误拒绝真实零假设的概率控制在约0.05。GH使用近似自由度和q参照，这里的同时覆盖率与错误控制也都是近似的。
至此，Welch给出整体判断，GH按式（8）对预定的全部三对进行调整，进一步估计各对差异。
六、把三对全部算完，再读结论
先完整算G3−G1。它的样本均数差为17.787500−9.630833＝8.156667 mmHg，刚才已算得SE＝1.884437 mmHg，ν＝11.290574。按式（7），8.156667除以1.884437得到t＝4.328436，乘√2后得到q＝6.121333。
为具体看清t与q的关系，先把G3−G1作为预先指定的单对比较。沿用表1的数据与模型条件，作H0：μ3＝μ1的双侧Welch t检验，α仍为0.05。再把相同t转为q，分别使用k＝2和本题全部三组的k＝3计算尾概率。
R的pt()返回t分布累计概率，取负的绝对t值并乘2得到单对双侧P。ptukey(q, nmeans, df, lower.tail = FALSE)计算q参照的右尾概率；nmeans = 3是比较族的组数，df填当前组对的自由度。qtukey(0.95, 3, df)返回95%分位点；除以√2把q尺度还原到均数差标准误的尺度[5]。
# 这两个v来自G1、G3各自的样本方差除以12。
x1 <- h$value[h$group == "G1"]
x3 <- h$value[h$group == "G3"]
v1 <- var(x1) / length(x1)
v3 <- var(x3) / length(x3)
difference <- mean(x3) - mean(x1)
se <- sqrt(v1 + v3)
nu <- (v1 + v3)^2 / (
  v1^2 / (length(x1) - 1) + v3^2 / (length(x3) - 1)
)
t_observed <- difference / se
q_observed <- sqrt(2) * abs(t_observed)
p_single <- 2 * pt(-abs(t_observed), df = nu)
p_q_two <- ptukey(q_observed, 2, nu, lower.tail = FALSE)
p_adjusted <- ptukey(q_observed, 3, nu, lower.tail = FALSE)
q_critical <- qtukey(0.95, 3, nu)
half_width <- q_critical * se / sqrt(2)
round(c(difference = difference, SE = se, df = nu,
        t = t_observed, q = q_observed, q_critical = q_critical,
        lower = difference - half_width,
        upper = difference + half_width,
        P_single = p_single, P_q_k2 = p_q_two,
        P_adj = p_adjusted), 6)

七、近期研究怎样使用这两个检验？
下面两项2025—2026年的研究，也采用了Welch整体比较与Games–Howell两两比较：一项比较牛牙釉质的硬度，另一项检查同一种气味在不同受试组中的评分差异。
（一）牙釉质：四组的平均显微硬度有差异吗？
Yerou等2026年的体外研究，将磷酸处理后的siwak植物材料制成牙膏，考察处理后牛牙釉质的显微硬度。研究将20颗不同的牛牙均分为四组：完好牙釉质、脱矿后立即测量、脱矿后接受7天siwak牙膏方案、脱矿后接受7天羟基磷灰石牙膏方案。每颗牙测量5处压痕，取平均值作为一个牙齿硬度值参与分析，因此每组样本量为5颗牙[7]。
作者因各组离散程度不同，采用Welch整体检验，再用Games–Howell比较全部六个组对。原文报告F(3, 7.71)=813.21，P<0.0001；但两个牙膏方案组的平均维氏硬度分别为300.19和295.25 HV，前者的样本均数高4.94 HV，GH调整P=0.863，尚未检出这两个方案的总体均数差异。这里同样能看到：整体比较显著，具体组对仍需分别读结果。 两个处理组都经历了牙膏处理和人工唾液储存，硬度结果对应这套完整的7天方案[7]。
（二）嗅觉：同一种气味在九个受试组中评分一致吗？
Bierling等2025年发表了一套74种单分子气味的嗅觉数据库。其中1119名健康受试者分属九个受试组，每组评价10种气味：8种只在该组出现，另有2种气味由九组共同评价，供组间对照。受试者通过视觉模拟量表，对每种气味的愉悦度、强度等8个维度评分。作者据此考察同一种共同气味的评分是否随受试组而变化[8]。
原文表2对每一种共同气味的每一个评分维度分别做Welch整体比较，每次比较九组均数；相应的GH比较族包含这九组的全部36对。原文表3列出了其中达到显著水平的组对：例如乙酸苄酯的强度评分，第1组均数为54.425分，第8组为71.360分，前者低16.935分，GH调整P<0.001。对应本文，就是把“下降值”换成“同一种气味的某一项评分”，比较九组的总体均数[8]。
八、本篇知识总结
回到开头的问题：方差不齐时，如果关心的仍是总体平均下降多少，就要保留均数这个目标，按各组自身的波动估计不确定性。
• 均数方差越小，均数估计越精确。 组内观测独立、总体方差为σi2时，均数方差为σi2/ni；以si2/ni估计它，倒数就是Welch的精度权重。
• Welch按各组均数的精度作整体比较，使用近似F参照。 加权中心、均数偏离和有限样本校正共同构成统计量，用来检验多个总体均数是否全相等。
• Games–Howell沿用每对Welch t的标准误和自由度，以全组极差参照作近似调整。 √2连接t与q的尺度；全体组数k和当前组对自由度共同确定q参照，给出调整P值与近似同时区间。
• 均数差、同时区间和调整P共同描述差异及其不确定性。 差值保留方向和单位，区间反映估计精度，调整P对应预定比较族中的检验判断。
