# 统计课堂47｜ANOVA效应量

图文与三语配套：《方差分析的差异有多大？η²、ω²与偏η²怎样理解？》

- 读文章：`公众号稿.md`为唯一正文源；双击`手机预览.html`查看网页排版。`公众号草稿预览.html`来自微信官方读回正文，图片映射到已核对的同目录素材；手机模拟检查宽度为390px。
- 做练习：进入`练习项目`，先读其中README；也可使用同目录项目ZIP解压后的独立入口。
- 复用配图：`文章配图`含无姓名课堂封面、2张数据图、12张高清公式PNG。公式保留alt（正文）、LaTeX（`formulas.tex`）及结构化源（`formulas.json`）。
- 重建配图：具备Python、numpy、pandas、matplotlib后运行`python 图源/generate_article_figures.py`。
- 重建HTML：运行`python 图源/build_preview.py`；仅使用Python标准库。HTML从正文生成，图片使用同目录相对路径，移动预览时请带上文章配图。

知识总结之前增加两项2026年原始研究应用：Doba等的普通ANOVA ω²，以及Wu等基线调整ANCOVA的偏η²。研究数字按原文归属，未另设需要原始个体数据的复算练习；原文链接在正文。

主例为四种孔结构各5个独立试件，压缩模量单位MPa。20个数字来自李春喜等《生物统计学》第6版例7-1，本篇只改情境、单位，并非真实支架实验。辅助2×2例的8个数字为人工教学值。

主例复算：SSB=15.4495，SSW=6.8560，SST=22.3055，η²=0.6926318621，ω²=0.6230315827，调整R²=0.6350003362。A1−A3=1.10 MPa，四组6对Tukey同时95%CI约[−0.084476，2.284476] MPa。
