# 小样本率的置信区间：从 6/13 找到上下限

这个配套项目对应公众号文章《小样本率的置信区间从哪里来？从6/13一步步找到上下限》。数据是教材案例的教学参数：13名妇女中观察到6名受孕；它不是可供重新分析的个人原始数据。三种语言使用同一组 `x = 6`、`n = 13`、双侧 `α = 0.05`。

## 先运行哪一个文件

完整下载并解压后，进入本目录。用自己熟悉的一种语言即可：

- R：打开 `小样本率区间估计.Rproj`，在 `代码/small_sample_proportion.R` 中点击 Source。只使用R基础包。
- Python：在Spyder中打开 `代码/small_sample_proportion.py`，按F5运行。也可以在终端用下面的命令运行；依赖见 `requirements.txt`。
- MATLAB：打开 `代码/small_sample_proportion.m` 后点击 Run。脚本自动定位本项目目录，不需要永久加入搜索路径；需要 Statistics and Machine Learning Toolbox 中的二项分布函数。

三种脚本都先显示或保存样本率与Wald近似区间，再计算二项尾概率。主线是：先用步长0.001扫描，找到下限约0.19—0.20、上限约0.74—0.75的夹逼区间；随后从这个区间二分20轮，并再多算若干轮保存高精度端点。二分历史只展示数值求解过程，不改变统计定义。

## 结果在哪里

每种语言各写入自己的目录，避免互相覆盖：

```text
运行结果/R/
运行结果/Python/
运行结果/MATLAB/
```

主要文件如下：

- `关键结果.csv`：样本率、Wald区间、二项精确端点、0/10边界参考值与9/10检验参考值。
- `扫描表.csv`：候选p从0到1、步长0.001时的两侧尾概率。
- `二分历史.csv`：从扫描所得夹逼区间开始的前20轮，包含每轮候选p和尾概率。
- `0_10边界.csv`、`9_10参考.csv`：文章中的边界与P值核对。

Python入口还会在 `文章配图/` 生成两张尾概率图；运行后可把它们与项目根目录旁的文章配图进行核对。图中横轴是候选总体率p，纵轴分别是 `Prₚ(X≥6)` 和 `Prₚ(X≤6)`，水平线为0.025。为方便手机查看，图的纵轴局部显示0—0.10，较大的尾概率曲线段会被裁掉。

图脚本优先注册用户字体目录中的Noto Sans CJK；找不到时再从Matplotlib系统字体清单寻找Noto/PingFang/Hiragino/STHeiti，最后使用DejaVu Sans。字体选择写在脚本里，不依赖某台电脑的绝对路径。

## 读结果时记住三件事

1. `right_tail = 1 - pbinom(5, 13, p)`（或Python/MATLAB对应函数）包含 `X = 6`，用于求下限。
2. `upper_tail = pbinom(6, 13, p)`包含 `X = 6`，用于求上限。
3. Clopper–Pearson区间是两个等尾单侧检验的反演。二项分布的离散性使实际覆盖率通常略高于95%，不代表区间总是最短。

练习：把 `数据/案例参数.csv` 中的 `x` 改成0、`n`改成10并重新运行，比较双侧95%上限约0.308497与单侧95%上限约0.258866。修改数据后生成的图只用于学习，不直接替换文章基准图。

教材案例来源：颜艳，《医学统计学》第5版，例6-2、例6-5，第92—94页。方法参考：R官方 `binom.test` 文档 https://stat.ethz.ch/R-manual/R-devel/library/stats/html/binom.test.html；Clopper & Pearson (1934) https://doi.org/10.1093/biomet/26.4.404。
