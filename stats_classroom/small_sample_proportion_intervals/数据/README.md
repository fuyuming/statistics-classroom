# 数据说明

`案例参数.csv` 是理论计算参数，不是个人级原始观测数据。它把教材案例中的观察结果写成脚本可读取的输入：

| 字段 | 含义 | 本例 |
| --- | --- | ---: |
| `x` | 观察到的成功数（受孕人数） | 6 |
| `n` | 固定试验次数（妇女人数） | 13 |
| `confidence` | 双侧置信水平 | 0.95 |
| `alpha` | 双侧显著性水平 | 0.05 |
| `scan_step` | 候选p的扫描步长 | 0.001 |
| `bisection_rounds` | 保存的教学二分轮数 | 20 |
| `案例说明` | 参数来源的文字说明 | 壶腹部吻合术后受孕教材案例 |

教材来源：颜艳《医学统计学》第5版例6-2、例6-5，第92—94页。模型假设为固定n、二分类结果、独立观察和共同成功概率p。项目不包含妇女姓名、手术记录或其他可识别信息。
