结婚率高的地方，离婚率也高，是结婚率的影响吗？抗真菌处理让植物长得更好，为什么回归里加上“是否有真菌”，处理的作用却消失了？这一讲，我们一起看：一个变量该不该放进模型，究竟取决于什么。

大家好，我是明哥。

一项抗真菌处理让植物长得更好。分析时，我们把“有没有真菌”也放进回归，想排除它的干扰，处理的作用却消失了。

是处理没用，还是我们比较的方法出了问题？

这正是本讲要回答的事：回归里多加一个变量，为什么反而可能把有效算成无效，甚至算出本来没有的关系？

关键在于，多加一个变量，就是要求在这个变量相同的条件下比较。若它是共同原因，这样做有助于排除干扰；若它正是处理发挥作用的一环，就可能把我们想研究的作用一起排除。

我们沿着作者的顺序，先看婚姻数据：为什么有时需要加变量；再看植物、基金和幸福的例子：同样的动作，为什么又可能加错。原课把这些关系画成“叉”“管”“对撞”和“后代”，每一种都对应一种不同的比较。

本文结合作者2023年第05讲的PPT和视频，原书补充计算。各节页码对应原课PDF。R短代码可按顺序运行，也可打开文末的完整跟读脚本。

一、什么时候需要加变量？先看共同原因（第9—15页）

“在年龄相同的人中，运动多的人是否更健康？”这句话已经限定了比较范围：先让年龄相同，再比较运动和健康。这就是这里说的“控制年龄”，统计上也叫条件化。

图1换成三个字母：我们想研究X与Y，但Z同时影响它们。这样的共同原因，可能让X和Y一起变化。

图1｜按PPT第10页重绘。Z分别影响X和Y。箭头从原因指向结果；这里没有X到Y的箭头。

作者先用一个简单模拟说明。X、Y、Z都只有0和1两种状态。Z有一半机会为0，另一半为1：

  • Z=0时，X和Y各有10%的机会为1。
  • Z=1时，X和Y各有90%的机会为1。

确定Z以后，X和Y各自抽一次签，互不影响。按两类各100人换算，平均会得到下面的人数。实际抽签的次数有限，人数会有出入。

所在人群X=0、Y=0X=0、Y=1X=1、Y=0X=1、Y=1
Z=0，按100人换算81991
Z=1，按100人换算19981
合在一起，按200人换算82181882

第一行的81来自100×90%×90%，1来自100×10%×10%。另外两格都是100×90%×10%=9。

如果不管Z，直接比较X不同的人：X=1的100人里，82人的Y=1；X=0的100人里，只有18人的Y=1。两边差得很大。

问题是，这两批人的Z也不同。前一批有90人属于Z=1，后一批只有10人。而Z=1的人，本来就更容易出现Y=1。

这样算出的82%与18%，混入了Z的影响。研究X对Y的作用时，Z就是需要考虑的混杂因素。

现在分开比较。只看Z=0的人，X=1组中Y=1的比例是1÷10=10%，X=0组是9÷90=10%。只看Z=1的人，两边分别是81÷90=90%和9÷10=90%。

Z相同以后，X不同，Y的比例却一样。 这套模拟中的关联，全是共同原因Z造成的。知道X有助于猜测Y，但主动改变X并不会改变Y。

下面用R核对。每个向量的两项，依次对应Z=0和Z=1。

n_x1 <- c(10, 90)   # 两个Z组内，X=1的总人数
n_x0 <- c(90, 10)   # 两个Z组内，X=0的总人数
y1_x1 <- c(1, 81)   # 其中Y=1的人数
y1_x0 <- c(9, 9)
c(全体X1 = sum(y1_x1) / sum(n_x1),
  全体X0 = sum(y1_x0) / sum(n_x0)) # 0.82与0.18
cbind(Z = 0:1, X1组 = y1_x1/n_x1, X0组 = y1_x0/n_x0)

这里控制Z，是为了不把Z造成的差异算到X头上。真实研究中，X也可能对Y有作用，调整后仍会留下关系。判断谁是共同原因，需要了解事情怎样发生，不能只看调整前后的数字。

接下来，把X、Y、Z换成结婚率、离婚率和结婚年龄。

二、一个该加的变量：结婚年龄（第16—25页）

作者使用rethinking包里的 WaffleDivorce 数据。每行是一个州或特区，共49州和哥伦比亚特区，缺少内华达州。

结婚率、离婚率来自2009年美国社区调查，单位均为每千名成年人对应的人数；结婚年龄是2005—2010年的结婚年龄中位数，单位为岁。先看三行实际数据：

数据中的一行M：结婚率（每千名成年人）D：离婚率（每千名成年人）A：结婚年龄中位数（岁）
阿拉巴马州（Alabama）20.212.725.3
加利福尼亚州（California）19.18.026.8
哥伦比亚特区（District of Columbia）17.76.329.7

在这些地区，结婚率高的地方，离婚率也往往高。作者提出一种解释：人们结婚较早的地区，结婚率可能较高，离婚率也可能较高。

图2画出了这个假设。我们要考察M对D的作用，同时考虑A对两者的影响。

图2｜按PPT第20—23页重绘。A为结婚年龄中位数，M为结婚率，D为离婚率。M到D的箭头表示待考察的作用。

按照这张图，结婚年龄A就是上一节的共同原因Z。于是问题变成：结婚年龄相近的地区，结婚率越高，离婚率还会越高吗？

拟合前，作者先把三列数据标准化。这样可以用相近的数值尺度设置先验，公式1给出了换算方法。

公式1｜把原始数值换成“距平均值多少个标准差”。横线表示样本均值，s为样本标准差；M、D、A分别按各自的均值与标准差换算。

这份数据中，结婚率的均值约20.11，标准差约3.80；结婚年龄的标准差约1.24岁；离婚率的标准差约1.82。

所以，标准化后的结婚率增加1，对应原来增加约3.80人/千名成年人；结婚年龄增加1，对应增加约1.24岁。后面算出的离婚率变化，乘以1.82就能换回原来的单位。

在解压后的项目根目录运行以下代码，先读数据，再分别标准化：

d <- read.csv("数据/v2/WaffleDivorce.csv")
head(d, 3)  # 先核对原始数值
zscore <- function(x) as.numeric(scale(x))
dat <- list(D = zscore(d$Divorce),
            M = zscore(d$Marriage),
            A = zscore(d$MedianAgeMarriage))

三、加入年龄以后，回归在比较什么？（第22—32页）

前面已经说明为什么要考虑结婚年龄。现在把M和A一起放进模型，看看“加入年龄”具体怎样改变比较，见公式2。

公式2｜离婚率的贝叶斯回归模型。第一行描述各地区离婚率围绕预测均值的波动，第二行用结婚率M和结婚年龄A计算该均值；Normal括号内依次是均值、标准差。

第一行说，各地区的离婚率围绕模型预测的均值波动，波动大小用σ表示。第二行计算这个均值：基准加上结婚率这一项，再加上结婚年龄这一项。

四个参数各有自己的含义：

  • α：结婚率和结婚年龄都处于平均水平时，预测的平均离婚率。
  • βM：年龄相同，结婚率增加一个标准差，平均离婚率改变多少个标准差。
  • βA：结婚率相同，结婚年龄增加一个标准差，平均离婚率改变多少个标准差。
  • σ：这两项还没有解释的地区差异有多大。

第一节的Z只有两种状态，容易分组。这里的年龄是连续的，50个地区中未必有年龄完全相同的两个地区。回归通过公式来完成比较：固定A，α+βA×A就是这个年龄下的基准，再看M变化时预测值怎样变。

换一个A，基准也换了。这个模型让不同年龄共用同一个βM，这也是它作出的假设。

先验：拟合之前，哪些数值比较可信？

选好要比较的变量后，还要估计它们的系数。先验和后验计算回答的是“系数可能多大、还剩多少不确定性”；该不该加入年龄，则由前面的因果假设决定。

作者最初给截距和斜率都设了Normal(0,10)先验。这里的10是标准差。这样的先验很宽，容易抽出特别大的斜率：结婚年龄变动一点，预测离婚率就变动很多。

他随后采用公式3中的先验。

公式3｜拟合前对参数范围的设定。α为截距，βM和βA为两条斜率，σ为残差标准差；Normal的第二项是标准差，Exponential的括号内是速率。参数均对应标准化后的模型。

两条斜率都用Normal(0,0.5)。正负方向各占一半概率，约95%的概率落在−1到1之间：我们事先不偏向上升或下降，但认为特别陡的关系较少见。α用更窄的Normal(0,0.2)，让基准值集中在0附近。

这三个先验分别设定。例如，给α选了一个值，并不会改变βM的先验分布。这叫先验独立。数据进入模型后，参数要共同解释数据，它们的后验可以相关。

σ是波动大小，正态模型要求它大于0。作者选用Exponential(1)，即速率为1的指数分布。它给σ在0到1之间约63%的概率，在1到2之间约23%的概率，大于3的概率约5%。

这就是该先验的实际含义：较小的剩余波动比较常见，特别大的波动较少见。 σ=1对应原尺度的标准差约1.82人/千名成年人。指数分布是满足正值要求的一种选择，不是唯一选择。

公式4写出它的密度和均值。

公式4｜指数分布怎样分配σ的先验概率。λ为速率，p(σ)为概率密度，E(σ)为先验均值；某个区间的概率等于密度曲线在该区间下方的面积。

速率λ越大，概率越集中在0附近；均值为1÷λ。因此Exponential(1)的均值是1，但σ并没有被固定为1。拟合以后，数据会更新对σ的判断。

这些先验会画出什么样的关系？图3把较宽和较窄的先验放在一起比较。右边仍允许上升、下降和平缓的线，只是减少了极陡的线。

图3｜按PPT第26—29页的参数重绘。把标准化结婚率固定在0，两边各画20条从先验抽出的平均关系线；横纵轴尺度相同。右图的均值线集中在中央。

用quap计算后验

这一讲沿用作者的 quap，没有使用网格近似。网格法逐个计算候选参数组合；quap先找到后验峰值，再用峰值附近的曲率，构造一个联合正态分布来近似后验。

本例有四个未知参数，每个取100个网格点，就有1亿种组合。quap省去了这一步遍历，但若后验明显偏斜或有多个峰，近似可能不好。“二次近似”指的是对数后验在峰值附近的近似方法。

下面的R代码对应公式2和公式3。dnorm的第二项是标准差，dexp填速率，start给出优化起点。

library(rethinking)
fit <- quap(
  alist(D ~ dnorm(mu, sigma),
        mu <- a + bM*M + bA*A,
        a ~ dnorm(0, 0.2),
        bM ~ dnorm(0, 0.5), bA ~ dnorm(0, 0.5),
        sigma ~ dexp(1)),
  data = dat,
  start = list(a=0, bM=0, bA=-0.5, sigma=0.8)
)
precis(fit, prob = 0.89) # 查看均值、SD和89%区间，重点看bM、bA

得到的两条斜率如下，图4同时画出了区间。

参数近似后验均值中间89%的后验区间
结婚率斜率βM−0.065−0.306～0.176
结婚年龄斜率βA−0.614−0.855～−0.372

图4｜点为近似后验均值，线为中间89%的后验区间。两个参数都在标准化尺度上。

考虑结婚年龄以后，βM靠近0，区间中既有负数，也有正数。原先看到的正关联明显减弱了，但现有数据还不能确定剩余关系的方向。

βA约为−0.614。换回原单位：结婚率相同时，一个地区的结婚年龄中位数高1.24岁，模型预测的离婚率平均低约0.614×1.82=1.12人/千名成年人。

婚姻例子说明了加变量能帮忙的情况：按图2的假设，加入年龄，是为了避免把年龄造成的差异算到结婚率头上。这个判断依赖图中的关系和对其他共同原因的处理，不能只因为系数变小了，就认定加得正确。

四、加了变量，系数的含义也要说清楚（第33—38页）

加入年龄以后，βM回答的是“年龄相同时，结婚率不同，预测离婚率差多少”。下面用两次预测核对这个含义。读清系数在比较什么，才能判断它是否回答了原来的问题。

设想同一个地区的两种情况，两次使用同一组参数：

  • M=0：结婚率为样本平均水平，约20.11人/千名成年人。
  • M=1：比平均水平高一个标准差，约23.91人/千名成年人。

年龄A相同，所以公式2中的α和βA×A都相同。只有结婚率这一项从βM×0变成βM×1。两次均值相减，差就是βM，见公式5。

公式5｜固定相同结婚年龄a，将标准化结婚率从0改为1，模型预测均值的差为βM。这里比较均值，尚未加入两次预测各自的随机残差。

图中的小写a表示固定的年龄，与截距α不同。暂用βM的后验均值−0.065代入，预测均值就降低0.065个离婚率标准差，换回原单位约为0.12人/千名成年人。

实际计算会使用许多组后验参数。R代码中，post每行是一组参数，age_same为每行抽取一个年龄；两次预测共用这一行的参数和年龄。

set.seed(20261009)
post <- extract.samples(fit, n = 10000) # 从quap近似后验抽样
post <- post[post$sigma > 0, ]          # sigma必须为正
age_same <- sample(dat$A, nrow(post), replace = TRUE)
mu0 <- with(post, a + bM * 0 + bA * age_same)
mu1 <- with(post, a + bM * 1 + bA * age_same)
delta_mean <- mu1 - mu0
all.equal(delta_mean, post$bM)         # TRUE：核对斜率含义
quantile(delta_mean, c(0.055, 0.5, 0.945))

all.equal返回TRUE，说明均值差逐行等于βM。最后一行给出均值差的后验中位数和89%区间。这是在用计算核对斜率的含义。

从预测差到干预效果

作者进一步问：如果主动把一个地区的结婚率从M=0改为M=1，会发生什么？他把主动设定M写作 do(M)。

通常图2中A会影响M；现在M由我们指定，所以去掉A→M，保留A→D。这样模拟的差，才是在这套因果假设下改变M的效果。仅仅算出两个预测值之差，并不能证明这些假设正确。

PPT还分别生成了两次可能的观测值，各自加上随机波动：

D0 <- rnorm(nrow(post), mean = mu0, sd = post$sigma)
D1 <- rnorm(nrow(post), mean = mu1, sd = post$sigma)
delta_observed <- D1 - D0
c(均值差的后验SD = sd(delta_mean),
  两次观测之差的SD = sd(delta_observed))

这时差值包含两部分：参数尚未确定带来的不确定性，以及两次观测本身的随机波动。因此，它通常比均值差更分散。图5比较的就是这两个结果。

图5｜青色为βM的近似后验，赭色为两次独立预测结果之差的分布。赭色曲线还包含两次观测各自的随机波动；两条曲线下的面积都为1。

在这个加法模型里，均值差恰好等于一条斜率。以后加入曲线或交互作用，就未必如此。作者在这里介绍“设定两种情况、分别预测、计算差值”，也是为后面的模型作准备。

五、第一种加错：把处理的帮助一起排除了（第40—51页）

先回到图2。研究结婚率M对离婚率D的作用时，年龄A是共同原因。若改问年龄A对D的总作用，M的位置就不同了：A可以影响M，M再影响D。固定M，会让这一路上的作用不再计入年龄的总作用。

同一个变量要不要控制，要看我们问的是什么。 作者接着用植物实验说明这一点。

100株植物，50株接受抗真菌处理，另外50株不处理。记录开始和结束时的株高，以及有没有真菌。我们想知道：处理能否让植物多长一些？

图6中，处理减少真菌，真菌又影响生长。这种作用经过一个变量传到另一个变量的关系，叫“管”。真菌是中间变量，统计学上也叫中介变量。

图6｜按PPT第48页重绘。H0、H1分别是初始与最后的株高，F表示是否出现真菌。原课图还保留了处理直接影响株高的可能；下面的模拟则特意设定，处理只通过减少真菌帮助生长。

原书第171页的模拟规定：无真菌时，植物平均增长5；有真菌时，平均增长2。处理只减少真菌，不另外促进或抑制生长。这里的增长是前后株高之差，沿用模拟的单位。

不处理时，出现真菌的概率是50%；处理后降到10%。按每组50株计算，平均株数如下：

每组50株无真菌，平均增长5有真菌，平均增长2
不处理25株25株
接受处理45株5株

不处理组平均增长：(25×5+25×2)÷50=3.5。

处理组平均增长：(45×5+5×2)÷50=4.7。

两组相差1.2。这就是处理通过减少真菌带来的平均帮助，也就是这套模拟的总效应。

如果把“是否有真菌”加入回归，比较方式就变了：无真菌的只和无真菌的比，有真菌的只和有真菌的比。

无真菌时，两组都长5；有真菌时，两组都长2。组内的差都是0，因为模拟规定处理没有其他作用。这个0回答的是：除了减少真菌，处理还带来多少额外帮助？ 这里称为直接效应。

所以，总效应为1.2、直接效应为0并不矛盾。处理本来就是靠减少真菌起作用；要求两边真菌状态相同，就把这份帮助从比较中去掉了。

用R把两种比较放在一起：

p_fungus <- c(不处理 = 0.5, 处理 = 0.1)
mean_growth <- (1-p_fungus)*5 + p_fungus*2
mean_growth                       # 3.5、4.7
unname(mean_growth[2]-mean_growth[1]) # 总效应1.2
c(无真菌时 = 5-5, 有真菌时 = 2-2)     # 两组内的差都为0

这就回到了开头的疑问。处理确实有用，但加入真菌后，系数回答的是“真菌状态相同时，处理还有没有额外帮助”。错在拿这个答案去回答“处理总体有没有用”。 若我们问的就是额外作用，这样比较又是另一个研究问题。

六、第二种加错：把本来没有的关系算出来了（第52—65页）

植物例子把已有的作用排除了。接下来的错误相反：本来没有的关系，分组以后出现了。先看基金申请怎样被筛选，再看回归里加一个变量为什么也能造成类似结果。

作者假设基金申请有两项评分：新颖性和可信度。在全部申请中，两项评分互不相关，但两项都能增加获资助的机会。图7中的箭头因此汇到同一个结果上，作者称它为“对撞点”。

图7｜按PPT第58—60页的基金例子重绘。青色框是两项评价，赭色框是被用来筛选的资助结果。箭头表示两项评价都影响资助机会。只保留赭色框中“获资助”的申请，便会改变两项评价的搭配。

为了算清筛选的影响，我们把PPT第55页的0／1规则用在基金例子上：至少一项评分高，获资助概率为90%；两项都低，概率为20%。这是本文把两个教学例子连接起来的演示。

设四种申请各100份，按上述概率计算，平均获资助份数如下。

申请的两项评价全部申请获资助概率获资助的期望份数
新颖性低、可信度低10020%20
新颖性低、可信度高10090%90
新颖性高、可信度低10090%90
新颖性高、可信度高10090%90

筛选前，新颖性低的200份中，100份可信度高，占50%；新颖性高的200份中也是50%。

只看获资助者，新颖性低的剩110份，其中90份可信度高，占90÷110≈81.8%；新颖性高的剩180份，其中90份可信度高，占90÷180=50%。

于是，新颖性低的获资助申请，反而更常有较高可信度。原因是两项都低的申请大多被淘汰了：新颖性低却能留下来的，更多靠可信度高；新颖性高的，可信度低也有较多机会留下来。

这个负关联由筛选造成，不能据此说新颖性会降低可信度。

R代码只做一件事：比较筛选前后可信度高的比例。

# 四项依次为：低低、低高、高低、高高（新颖性在前）
all_n <- c(100, 100, 100, 100)
funded_n <- all_n * c(0.2, 0.9, 0.9, 0.9)
trust_rate <- function(n) {
  c(新颖性低 = n[2]/sum(n[1:2]),
    新颖性高 = n[4]/sum(n[3:4]))
}
rbind(全部申请 = trust_rate(all_n),
      获资助者 = trust_rate(funded_n))

输出从50%与50%，变成约81.8%与50%。两项评分没有被改动，留下来的申请变了。

在回归里分组，也会发生类似的事

基金例子是拿到样本前就筛过了。图8的例子则保留全部人群，却在分析时按婚姻状态比较。

作者的模拟规定：每个人的幸福程度一生不变；较幸福的人在每一年里结婚的概率更高；结婚后一直保持已婚。年龄越大，也就经历了更多次结婚机会。

图8｜按PPT第63—65页及原书第177—179页重绘。青色框中的年龄与幸福程度共同影响赭色框中的婚姻状态。按已婚／未婚分组，或在回归中加入婚姻状态，都是在婚姻状态相同的人中比较年龄与幸福程度。

先看已婚者。较幸福的人往往更早结婚，所以年轻已婚者中，较幸福的人更多。时间久了，一些幸福程度较低的人也结婚了，进入已婚组。年长已婚者的平均幸福程度便可能低于年轻已婚者。

再看未婚者。较幸福的人更容易结婚，陆续离开未婚组。留下的年长未婚者中，幸福程度较低的人占比便更大。

按婚姻状态分别看，两组都可能呈现“年龄越大，幸福程度越低”。可是模拟中每个人的幸福程度根本没变，变的是各年龄组里有哪些人。

这里加错的是婚姻状态。 原问题是年龄是否影响幸福；加上婚姻状态后，模型变成分别在已婚者和未婚者中比较年龄。两组随年龄变化的人员构成，让模型看到了负关联。若据此说人会越老越不幸福，就把分组造成的关系当成了年龄的作用。

图8的婚姻状态和图7的资助结果一样，都是两边共同影响的结果。

七、第三种加错：换成检测指标，仍可能排除部分作用（第66—71页）

回到植物实验。我们未必能直接知道有没有真菌，但可以做检测。实际真菌状态影响检测结果，因此检测结果是真菌状态产生的下游变量，作者称为“后代”。

图9用这个补充例子解释原课的四个字母：X为处理，Z为真菌状态，Y为生长，A为检测结果。

图9｜沿用PPT第67—69页的X→Z→Y、Z→A结构，括号内的植物含义是本文补充解释。检测结果A由真菌状态Z产生，图中检测结果A不影响植物生长。

如果检测完全准确，要求两株植物检测结果相同，就等于要求它们的真菌状态相同。这样仍会去掉处理通过减少真菌带来的帮助。

如果检测有误差，阴性组里会混入漏检，阳性组里也可能有误报。但有用的检测仍能分出真菌较少和较多的两组。按检测结果分组，也就部分地按真菌状态分了组。

作者用0／1模拟这种情况：X有一半机会为1；Z有90%的机会与X相同；Y与A各有90%的机会与Z相同，分别独立抽取。A相当于一个正确率90%的Z记录。

图10比较不分组、按Z分组和按A分组后的相关。

图10｜按PPT第69页的二元规则精确计算。三根柱分别给出全体、Z=0组内、A=0组内的X与Y相关系数；选择Z=1或A=1结果相同。图中数值来自作者的二元模型，植物例子用于解释结构。

全体相关为0.640，按Z分组后为0，按A分组后约为0.390。A提供了一部分Z的信息，所以相关减弱；它不能完全反映Z，所以相关没有消失。

下面用R模拟。这里的A是二元记录，已不再表示婚姻模型中的结婚年龄。

set.seed(20261009)
n_sim <- 100000
X <- rbinom(n_sim, 1, 0.5)
Z <- rbinom(n_sim, 1, 0.1+0.8*X)
Y <- rbinom(n_sim, 1, 0.1+0.8*Z)
A <- rbinom(n_sim, 1, 0.1+0.8*Z)
c(全体 = cor(X,Y),
  固定Z = cor(X[Z==0],Y[Z==0]),
  固定A = cor(X[A==0],Y[A==0]))

结果应接近0.64、0、0.39。图10使用精确概率，代码是随机模拟，因此数字会略有差别。只把生成A时的概率改成0.5，再运行一次：A不再告诉我们Z是什么，按A分组的相关就应回到全体水平。

如果我们想估计处理的总作用，只避开真菌状态本身还不够。加入反映它的检测结果，也可能让一部分作用从处理系数中消失。变量的名字换了，并不代表它对比较的影响就换了。

后代也能帮忙。作者还举出：共同原因U没有测到，但U会影响两个可测指标。若这些指标能充分反映U，并有合适的测量模型，就可能借它们处理U带来的混杂。关键仍是先弄清测量反映了什么。

八、一个变量，可能同时扮演两种角色（第72页）

前面每次只看一种简单关系。真实研究中，它们常常连在一起。图11以祖辈、父母、孙辈为例，父母变量P同时出现在两条路上。

图11｜按PPT第72页重绘。U是未测量的共同原因，同时影响父母变量P和孙辈结果C。

一条是祖辈影响父母，父母再影响孙辈。研究祖辈不经过父母的作用时，我们会想到控制P，去掉这条间接作用。

另一条路上，祖辈和未测量的U都影响P，U又影响孙辈。此时P也是一个共同结果。控制P会像筛选基金申请那样，让祖辈变量与U产生关联，进而影响我们对孙辈结果的判断。

同一次调整，可能同时去掉一条作用，又引入另一种干扰。所以，要把有关变量和箭头放在同一张图里检查。

回答标题：多加一个变量，错在哪里？

错不在变量多，而在于加进去以后，模型回答的问题变了，我们却还按原来的问题解释结果。

本讲的例子加入的变量对结果的影响
结婚率与离婚率结婚年龄按图中的假设，帮助排除共同原因造成的差异
抗真菌处理与生长真菌状态去掉了处理通过减少真菌带来的帮助，不能再用这个系数代表总作用
年龄与幸福程度婚姻状态分组后产生负关联，可能被误读成年龄使人不幸福
处理与生长真菌检测结果间接按真菌状态分组，也可能使估计的作用减弱

下一次准备加变量时，先问三件事：我想知道全部作用，还是某一部分作用？这个变量是两者的共同原因、处理后的结果，还是样本被筛选的依据？要求它相同以后，剩下的比较还能回答我的问题吗？

这些想清楚，再用贝叶斯模型计算系数及其不确定性。先验、quap和后验区间能帮助估计，但不会替我们判断变量该不该加。

下一讲，作者会把这些关系放进更复杂的因果图，继续讨论哪些控制有用、哪些会出错。
