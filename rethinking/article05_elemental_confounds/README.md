# 精读 05｜控制了一个变量，结论反而更错

《Statistical Rethinking》精读系列的配套代码。对应公众号「明哥的微生物世界 · Statistical Rethinking 精读 05」。

- 课程：Statistical Rethinking 2023 第 05 讲 *Elemental Confounds*
- 教材：McElreath, R. (2020). *Statistical Rethinking*（第 2 版）第 5 章与第 6 章开头
- 本篇讲什么：叉（混杂）、管（中介）、对撞（选择）、后代（治疗后变量）四种结构，以及"该控制什么、绝对不能控制什么"

## 目录

```
代码/    篇05_四种形状.R / .py / .m      三个语言的功能等价脚本（目录按脚本位置自动定位）
运行结果/ 00_教材数据_华夫饼与离婚率.csv  教材 WaffleDivorce（50 州）
         01_教材对照_分层相关.csv        全体与按南方/非南方分层的相关系数
         02_我们的案例_叉.csv           10 个实验单元（处理、批次、长势）
         03_叉_调整前后.csv             不调整 vs 把批次放进模型的处理效应估计
         04_我们的案例_管.csv           处理、菌群密度（中介）、长势
         05_管_总效应与直接效应.csv      不控制中介 vs 控制中介
         06_我们的案例_对撞.csv          处理、基线值、是否被选中
         07_对撞_条件化前后.csv          全体相关 vs 只看被选中的子集
         08_我们的案例_后代.csv          处理、处理后指标（后代）、长势
         09_后代_控制前后.csv            不控制后代 vs 把后代当协变量
```

## 怎么跑

1. **先跑 R**（导出教材数据）：
   ```bash
   Rscript 代码/篇05_四种形状.R
   ```
2. 再跑另外两个语言（读同一份 CSV）：
   ```bash
   python 代码/篇05_四种形状.py
   ```
   MATLAB：直接运行 `代码/篇05_四种形状.m`（脚本自动定位目录；拷到别处跑时可用环境变量 `RET_ROOT`）。
3. 对照 `运行结果/*.csv`，三语言输出**逐字节一致**。

## 方法与边界

- 全部用**显式最小二乘**（自己解正规方程）与**显式皮尔逊相关**，不用现成建模函数，保证三语言能用同一套运算顺序、输出逐位一致。
- 主线案例是**教学模拟数据**：生成机制写在脚本里（叉：`10 + 3·处理 + 2.5·批次 + 残差`；管：`密度 = 5 + 2·处理 + e1`、`长势 = 8 + 1.5·密度 + e2`；后代：`长势 = 9 + 2.8·处理 + 0.9·后代 + e`）。
- 每组的样本量只有 10（对撞那节是 10 选 5），**估计本身很抖**：正文里"调整后 3.425 也没正中 3.0"就是在说明这一点，不要读成"调整没用"。
- 教材对照用 `WaffleDivorce`；分层相关按 `South` 列分南方/非南方。
- 本篇只讲四种结构的**直觉判据**；后门准则与 d-分离留到第 06 篇。

## 练习开关（正文第六节）

- `treat_c`、`batch_c`、`resid_c`：叉那一节的数据（把批次改成随机分配，看偏倚消失）
- `density_d`、`growth_d`：管那一节
- `selected`：对撞那一节的入选规则（改阈值可看子集相关变化）
- `post_d`、`growth_p`：后代那一节
