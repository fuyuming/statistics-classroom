# 精读 01｜科学先于统计：泥人、DAG 与贝叶斯工作流

《Statistical Rethinking》精读系列的配套代码。对应公众号「明哥的微生物世界 · Statistical Rethinking 精读 01」。

- 课程：Statistical Rethinking 2023 第 01 讲 *Science Before Statistics*
- 教材：McElreath, R. (2020). *Statistical Rethinking: A Bayesian Course with Examples in R and Stan*, 2nd ed. 第 1、2 章

## 这一篇做了什么

1. **同一组数据、两个不同机制**：泊松（每个个体期望相同）与负二项（期望本身在变）的计数分布几乎重合，
   给出可核对的量化指标：理论概率的**全变差距离 0.035176**、最大单点概率差 0.015235。
2. **两种 DAG 结构**：混杂（共同原因）与对撞（共同结果），用 ggplot 直接画，不依赖 igraph。
3. **贝叶斯工作流五步**（课程里的「贝叶斯猫头鹰」）。
4. **网格近似走一遍**：抛球估地球水面比例，观测 (3 次里 2 次是水)、(9 次里 6 次)、(30 次里 20 次)。

## 运行

三个语言的脚本各自独立可跑，输出应当完全一致。

```bash
# R（主）
Rscript 代码/篇01_科学先于统计.R

# Python
pip install -r requirements.txt
python 代码/篇01_科学先于统计.py

# MATLAB（在 MATLAB 里直接运行，脚本自带 cd）
matlab -batch "run('代码/篇01_科学先于统计.m')"
```

输出：

- `运行结果/01_网格近似的后验汇总*.csv` —— 三组观测的后验均值、网格最大值点、89% 等尾区间、后验密度峰值
- `运行结果/02_两种过程的近似程度*.csv` —— 泊松与负二项的全变差距离、最大单点概率差
- 配图：运行脚本后在本目录生成 `文章配图/`（五张正文配图；`06-`、`07-` 是 Python、MATLAB 的同内容对照图）。
  仓库只放代码与运行结果，配图不入库——跑一遍脚本即可得到，且与正文用图完全一致。

## 数字（三语言逐位一致）

| 观测 | 后验均值 | 网格最大值点 | 89% 等尾区间 | 后验密度峰值 |
|---|---|---|---|---|
| 3 次里 2 次是水 | 0.598892 | 0.684211 | 0.2632 – 0.8947 | 0.093629 |
| 9 次里 6 次是水 | 0.636382 | 0.684211 | 0.4211 – 0.8421 | 0.142835 |
| 30 次里 20 次是水 | 0.656250 | 0.684211 | 0.5263 – 0.7895 | 0.244429 |

- 网格取 0 到 1 之间 **20 个等分点**，所以最大点是 13/19 = 0.684211，不是 2/3。
- **89% 区间用后验累积和取网格点算**（等尾区间），不用随机抽样——只有这样三个语言才能逐位一致。
