- 课程：Statistical Rethinking 2023 第 09 讲 *Modeling Events*

## 方法与边界（重要）

- **过离散检查必须按"同一剂量内"算**：本数据每个剂量有 3 个重复，过离散比 = Σ(剂量内方差) / Σ(剂量内均值)。把不同剂量混在一起算，得到的是剂量趋势，不是过离散（初版就是这么错的）。
- **有序模型用"切点固定、只估斜率"的一维网格**（c1 = 1.5、c2 = 0）。初版解"切点自由 + 识别约束"的两参数网格时，格子范围与单调性钳制把似然压成近似平坦，斜率估成 −0.05。教学演示用固定切点更清楚，真实分析应一起估切点。
- 概率曲线那一份 CSV 按 **3 位小数**写出：三语言的浮点求和顺序不同，4 位小数会在进位边界上出现末位差（实测过一次，差 0.0001）。
- 全部为教学模拟数据；截距与斜率用平坦先验；网格后验 300×300（有序部分是一维 400 点）。

## 练习开关（正文第五节）

- 定植：改 `n_units`（每剂量的单元数）
- 计数：改 `counts` 的重复散开程度 → 过离散比会变
- offset：删掉体积那一步（直接用计数建模）看"体积效应"是否被当成处理效应
- 有序：改 `c1_fix`（1.5 → 2.5）看斜率与两条累积概率曲线怎么动
