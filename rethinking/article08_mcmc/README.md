## 方法与边界（重要）

- **本篇的"随机数"是确定性 Halton 低差异序列**：提议步长由 `qnorm(Halton)` 给出、接受判断用 Halton 的均匀序列。算法结构与标准 Metropolis 一致，目的是让 R／Python／MATLAB 给出**逐位一致**的结果（真随机数做不到三语言一致）。**真实分析请用真随机数与多种子。**
- 似然用固定 σ（与第 03、04 篇同一简化），便于与网格解直接对照。
- 有效样本量与 R-hat 都是**简化版本**（`n_eff ≈ n(1−ρ₁)/(1+ρ₁)`；R-hat 用两条链的方差比），用于教学演示；正式分析请用 Stan／`cmdstanr` 自带诊断。
- "每秒十亿格点"只是量级演示，不是实测性能。

## 练习开关（正文第六节）

- 步长：`metropolis(...)` 的 `step_a`、`step_b`（例如把 0.9 改成 1.8，或 (0.5, 0.05)）
- 预热：`burn`（改成 200 看迁移段的影响）
- 链起点：`start`（把两条链起点都放到后验附近，看 R-hat 的变化）
- 步数：`n_step`
