# 校验记录（精读 02）

本目录的数字全部是**确定性计算**（整数路径计数、20 点网格、解析 Beta 分布、beta-二项预测），
R / Python / MATLAB 三个语言各跑一遍，**连 CSV 文件本身都逐字节一致**（见第 3 节）。

## 1. 四面地球仪：数路径

观测序列 W L W，四面地球仪（水面数 0–4）。

| 候选水面比例 p | 水面数 | 陆面数 | 路径数 | 后验 |
|---|---|---|---|---|
| 0 | 0 | 4 | 0×4×0 = 0 | 0 |
| 0.25 | 1 | 3 | 1×3×1 = 3 | 0.15 |
| 0.5 | 2 | 2 | 2×2×2 = 8 | 0.4 |
| 0.75 | 3 | 1 | 3×1×3 = 9 | 0.45 |
| 1 | 4 | 0 | 4×0×4 = 0 | 0 |

路径总数 = 20；后验 = 路径数 ÷ 20。

对照文件：`运行结果/01_四面地球仪路径计数*.csv`（三份逐字节相同）。

## 2. 20 点网格、解析解与预测

观测 9 次里 6 次是水（与精读 01 一致，便于两篇对照）。

| 先验 | 后验均值 | 最大点 | 89% 等尾区间（网格近似） |
|---|---|---|---|
| 平坦先验 | 0.636382 | 0.684211 | 0.4211 – 0.8421 |
| exp(-5·\|p-0.5\|) | 0.586171 | 0.526316 | 0.4211 – 0.7895 |
| p<0.5 时为 0 | 0.681388 | 0.684211 | 0.5263 – 0.8421 |

解析后验 Beta(7, 4)：

| 指标 | 值 |
|---|---|
| 后验均值 | 0.636364 |
| 后验众数 | 0.666667 |
| 后验标准差 | 0.138866 |
| 89% 等尾区间 | 0.400320 – 0.845431 |

- 20 点网格的均值 0.636382 与解析值 0.636364 相差 0.000018；**网格误差是算出来的，不是估出来的**。
- 预测：下一次取到水的概率 = 0.636364；未来两次取点的水数分布 = 0（0.151515）、1（0.424242）、2（0.424242）。

对照文件：`运行结果/02_三种先验下的后验汇总*.csv`、`03_解析后验对照*.csv`、`04_预测分布*.csv`。

## 3. 三语言逐字节一致（本篇比 01 篇更进一步）

三份 CSV **整文件 md5 相同**，不只是数据行相同。做法：

- 三个语言都用同一个数字格式化规则（保留 6 位小数后去掉多余的 0），并统一用"表头与字符列加引号、数字列不加引号"的写法；
- 二项似然不用各语言的库函数，按组合数直接算，避免库与库之间的尾位差异（Python 用 `math.comb`，MATLAB 用 `binopdf` 并与 R 的 `dbinom` 逐位核对）；
- 随机数一个都不用——本篇的图 1–5 全部是确定性计算。

## 4. 刻意的设计说明

- **分数不进正文**。后验 0.15 / 0.4 / 0.45 在脚本里是精确的 3/20、8/20、9/20，正文按小数写，便于和网格结果对照。
- **89% 区间的口径与 01 篇一致**：仍用"后验累积和首次达到 5.5% / 94.5% 的网格点"，所以同样只是**网格近似**（01 篇的 VALIDATION 第 5 节说明了它实际包含的概率会略超 89%）。
- **预测用 beta-二项**，不用抽样模拟，所以预测分布也是三语言逐位一致的。

## 5. 练习答案（供讲解用）

- 练习 1：把 `n_faces` 从 4 改成 6，路径数是 5、16、27、32、25（合计 105）。
- 练习 2：把判定取法从 3 种（判对 2、判错 1）改成 10 种（判对 9、判错 1），观测到"水"的路径数变成 3×9 + 1×1 = 28 条。
