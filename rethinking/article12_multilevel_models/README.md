# 精读 12｜多层模型入门：部分合并

《Statistical Rethinking》精读系列的配套代码。对应公众号「明哥的微生物世界 · Statistical Rethinking 精读 12」。

- 课程：Statistical Rethinking 2023 第 12 讲 *Multilevel Models*
- 教材：McElreath, R. (2020). *Statistical Rethinking*（第 2 版）第 13 章 *Models With Memory*
- 本篇讲什么：数据天然分组时，完全合并（忽略组）与完全不合并（各组单算）各错一边；多层模型用**部分合并**把每组的估计"往整体拉一点"，并把"组间真实差异 σ_α"与"组内观测噪声 σ"分开估

## 方法与边界（重要）

- **计算方式**：对 `(b, σ_α, σ)` 铺 60³ 网格，**组水平 α_j 与总体均值 μ 用解析积分消掉**（闭式边际似然）。所以网格只有三维、完全可复现，三语言能逐字节一致。边际似然的两部分各管一段：**组均值部分**提供 σ_α 与 σ 的信息，**组内偏离部分**提供斜率 b 的信息。
- **先验**：网格上放平坦先验，范围 b∈[0,2]、σ_α∈[0.005,2]、σ∈[0.05,2]。**范围就是先验**——改动范围会改变后验（第 11 篇的教训），所以把范围写在这里。
- **模型假设**：所有瓶**共用同一个斜率 b**（随机截距模型）；允许斜率随瓶变的是随机斜率模型。α_j 与误差都假设正态。
- **收缩公式**（每瓶孔数相同）：`α̂_j = μ̂ + (ȳ_j − μ̂)·σ_α²/(σ_α² + σ²/n)`。孔数不同时收缩因子随 n 变化。
- 数据为教学构造（12 瓶 × 3 孔）。
