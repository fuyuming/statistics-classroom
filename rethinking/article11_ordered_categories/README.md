## 方法与边界（重要）

- **切点次序由参数化保证**：`c1 = u`、`c2 = u + exp(v)`，网格上任意 (u, v) 都满足 c1 < c2。这避免了"两个独立切点 + 事后筛选"的浪费，也避免了切点写反（写反会让中间档的概率变成负数）。
- **不另设自由截距**：若既给切点自由、又给自由截距，同时给它们加同一常数不改变任何概率——那才是真正的识别冗余。标准 logistic 分布已固定潜在误差尺度。
- **三参数网格 70×70×70**，网格上放平坦先验；网格有限，边界处仍有取舍。
- 第 09 篇的"切点固定为 0 和 1.5"是本篇的简化版，**两篇的斜率数字不可直接比较**（切点假设不同）。
- 数据为教学构造（30 个观测）。

## 练习开关（正文第六节）

- 换成"两个独立切点 + 事后筛选"：结果几乎一样，但会丢弃一部分格点
- 只留轻与重、做成二分类数据：估出的斜率不是同一个量
- 加剂量二次项：网格维度与数据支撑能力的问题
- 改动剂量 3 那一组：三个切点的后验如何移动
