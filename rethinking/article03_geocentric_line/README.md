# 精读 03｜生物膜的趋势拟合得很准，下一次测量就能算准吗？

《Statistical Rethinking》精读系列的配套代码。对应公众号「明哥的微生物世界 · Statistical Rethinking 精读 03」。

- 课程：Statistical Rethinking 2023 第 03 讲 *Geocentric Models*
- 教材：McElreath, R. (2020). *Statistical Rethinking*（第 2 版）第 4 章「Geocentric Models」
- 本篇讲什么：一条直线（截距 + 斜率 + 误差）从生成模型到后验、再到两类区间的完整流程；先验预测模拟；二维网格近似；网格分辨率；先验敏感性

## 怎么跑

1. **先跑 R**（它负责把教材数据导出成 CSV）：
   ```bash
   Rscript 代码/篇03_一条直线.R
   ```
2. 再跑另外两个语言（读同一份 CSV，保证看到同一批数据）：
   ```bash
   python 代码/篇03_一条直线.py
   ```
   MATLAB：在 MATLAB 里直接运行 `代码/篇03_一条直线.m`（脚本自己定位目录；若把脚本拷到别处跑，可用环境变量 `RET_ROOT` 指向篇目录）。
3. 跑完对照 `运行结果/*.csv`：三个语言的文件**逐字节一致**（含 CSV 本身）。

## 方法与边界（读代码前请先看）

- 后验用**二维网格近似**（a、b 各 200 点），σ 由最小二乘残差代入后**固定**（这正是正文交代的简化：忽略了 σ 的不确定性）。
- 先验是参数框 `A_LIM`／`B_LIM` 上的**平坦先验**；正文图 1 的细线也从这个先验抽，前后一致。
- 所有"抽样"都用 **Halton 序列**（确定性）代替随机数，所以三语言可以逐字节一致、结果可复现；代价是它属于确定性近似，后验预测的区间有抽样分辨率限制（本篇用 2000 次抽样，报到 3 位小数）。
- 主线案例是**教学模拟数据**，不是真实实验结果。

## 练习开关（正文第七节）

- `A_LIM`、`B_LIM`：参数框（也是平坦先验的范围）
- `N_GRID`：网格密度（改小可以看到图 4 里后验均值的偏移）
- `prior_a`、`prior_b`：先验，给 `c(均值, 标准差)` 生效，`NULL` 表示在当前网格范围内平坦
- 主线案例数据：脚本顶部 `resid_fix`（12 个时间点的残差），换成自己的数据即可
