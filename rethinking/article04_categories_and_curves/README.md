## 方法与边界（读代码前请先看）

- 组均值与对比用**解析后验**：把合并组内标准差 1.18 当作已知的 σ，于是每组均值的后验是正态、差值的后验也是正态。代价是忽略了 σ 自身的不确定性（正式分析要把 σ 一起估）。
- 曲线部分全部用**显式最小二乘**（自己搭基函数、解正规方程），没有用现成的 `poly()`／`bs()`，这样三个语言能用同一套运算顺序、输出逐位一致。
- 线性样条写成 `1, t, (t−k₁)₊, (t−k₂)₊`；**结点位置是建模者的选择**，不是数据替你选的。
- 主线案例是**教学模拟数据**，不是真实实验结果。
- `P(差值>0)` 在当前精度下四舍五入为 1，正文按"方向没有含糊"来表述，没有写成"必然为正"。

## 练习开关（正文第七节）

- `groups`：三组的观测值（换成自己的数据即可）
- `resid_fix`：饱和曲线的 12 个残差
- `X_poly`、`X_spl`：多项式与样条的基函数（改阶数、改结点在这里改）
- 哑变量写法对照：把 `groups` 的处理列拆成两个 0/1 列，逐步比较后验
