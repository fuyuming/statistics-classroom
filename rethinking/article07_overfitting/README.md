## 方法与边界

- **留一交叉验证用闭式解**：对最小二乘，`LOO_i = 残差_i / (1 − h_ii)`，不用真的重复拟合 n 次。
- **多项式基用标准化后的时间轴**（否则 `t⁸` 之类的量级会让正规方程数值奇异——这是实测踩过的坑）。阶数封顶到 7：12 个观测下 8 个系数已经接近过参数化。
- **厚尾那一节是教学演示**：用 t 似然的 IRLS 一步近似（权重 `(df+1)/(df+z²)`，df 固定为 4），正式分析应在贝叶斯模型里联合估计自由度。
- 主线数据是**教学模拟数据**：生成均值是三次曲线，扰动对 `[1, t, t², t³]` 做了正交化，所以"3 阶"在样本内精确贴合；这也说明 LOO 选出的 2 阶**不是真值**——用样本外误差选模型同样受噪声与小样本影响。
- 全部用显式最小二乘解正规方程，无随机数；R／Python／MATLAB 三份输出逐字节一致（这只说明实现一致，不替代模型选择判断）。
