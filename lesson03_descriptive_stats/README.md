## 运行方法

**R**：双击本文件夹的 `医学统计学.Rproj`，再打开 `R/` 下对应脚本 Source（可逐段运行）。首次运行会提示安装缺失的包（需联网）；`2-3`、`2-13` 只用 base R，不装任何包也能跑。

**Python**：`python -m pip install -r requirements.txt`（numpy、pandas、scipy、matplotlib），然后运行 `Python/` 下同名脚本，例如：

```bash
python 2-11-正态分布.py
```

**MATLAB**：需要 Statistics and Machine Learning Toolbox；在本文件夹下打开 `MATLAB/` 中的同名 `.m` 运行（中文文件名可用 `run('2-11-正态分布.m')`）。

**结果保存**：默认就会写文件——R 存到 `output/R/`（图、表格、docx/pptx/svg 等；想只看控制台不生成文件时先运行 `options(medstats.export = FALSE)`），Python 存到 `output/Python/`，MATLAB 存到 `output/MATLAB/`。图中中文依赖本机中文字体，见下方排查说明。

## 几个容易误读的地方

- **构成比不是率**：2-3 里患者构成比最高的年龄组，患病率并不是最高的——分母不同，回答的问题也不同。
- **合计比例不能直接平均**：两家医院治愈率 40% 与 60%，合并要按人数加权（46.67%），不能取平均。
- **粗率比较要先看构成**：两组内部构成不同时先做标准化；标准化只调整选定的分层因素，不等于消除所有混杂，结果相对于所选标准构成。
- **几何均数（2-9）**：只适用于全部为正的数据；GM 与 GSD 应分别报告（GSD 是无量纲的倍数因子，不能写成"GM ± GSD"），GM/GSD ~ GM×GSD 不是均数的置信区间；计算 GM 不要求数据服从对数正态。MIC 这类数据常按二倍稀释测定，也可能出现超出检测范围的结果，报告时要说明处理方式；汇总的中心水平不能替代按折点进行的药敏判读。
- **变异系数（2-10）**：要求零点有自然意义、均数为正且远离 0；摄氏温度（零点人为约定）与 pH（本身是对数尺度）都不适合直接算 CV。CV 不受正比例单位换算影响，但不等于任意两个变量都可比。
- **小样本**：2-9 只有 10 个观测，取对数后图形更接近对称，但仅凭图形不能确认对数正态分布；正态性检验不显著也不等于证明正态。

## 中文乱码与字体排查

脚本注释乱码：先按正确编码重新打开，确认后另存 UTF-8，不要直接覆盖乱码文本。

数据乱码：本仓库 CSV 为 UTF-8，R 读取可用 `encoding = "UTF-8"`；如遇其他来源的 CSV，先核对其真实编码，不要忽略解码错误。

图上中文显示为方框：检查绘图字体，选择本机实际存在的中文字体（R 用 showtext；Python 用 `matplotlib.font_manager` 查询；MATLAB 用 `listfonts`）。改字体不能修复已经读错的文字。
